# Справка для вычета за фитнес

1. Новая заявка (форма, стойка, бот) — строка в `data/tax_requests.csv`; поля — только из CLAUDE.md.
2. `python3 .claude/skills/tax-certificate/tax_check.py --in-list <годы из настроек> --requests
   data/tax_requests.csv --payments data/payments.csv`. `можно = да` — готовим; `нет` — в `что_не_так` причины.
3. Черновик — `document-draft` по `templates/certificate-data.md` → `outbox/docs/<дата>-справка-<id>.md`. Сумма —
   из скрипта, не пересчитывать в уме. Срок выдачи — `workdays add <получено> <issue_workdays>`.
4. Вопрос «Справки готовы: N черновиков — выдать?»; проблемы — вопрос «… что отвечаем?» (первые три фамилии, без ИНН).
5. После «Выдать» — `статус = выдана`; сообщение плательщику «справка готова» — через `reminder-batch`.

# Продления: точки, риск, предложения

1. Скрипт — рядом, только стандартная библиотека:
   `python3 .claude/skills/renewal-risk/renewal_risk.py --today <сегодня> --members data/members.csv
   --visits data/visits.csv --points 60,30,7 --family-window 30 --out outbox/renewals-plan.csv`.
   В CSV — кому писать (точка, дней до конца, семья, предложение); в stderr — «Под риском» и «Пропущено».
2. `RISK.md`: высокий риск — первыми; по строке: имя, филиал, дней до конца, причины. Без телефонов.
   Вопрос менеджеру — «Под риском N — что делаем?», в тексте первые три имени и причины.
3. Пачки — по точкам: 60, 30, 7 — отдельно. Пустое `предложение` (нет согласия на рекламу) — только
   `templates/renewal-reminder.md`; иначе — `renewal-offer.md`, семья — `family.md` (поле `{семья}` — имена членов
   семьи из выгрузки). Скидка — только из настроек модуля.
4. `reminder-batch` → вопрос «Отправить пачку из N?» о каждой; после отправки — точка в `точки_отправлены`.

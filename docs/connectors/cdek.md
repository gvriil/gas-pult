# СДЭК — коннектор пульта

Код — `src/gas_pult/connectors/cdek_mcp.py`, тесты — `tests/test_cdek_mcp.py`, контракт — `docs/CONNECTORS.md`.
Документация API v2 — https://apidoc.cdek.ru/ (там же «Скачать OpenAPI спецификацию»).

## Что умеет

| Инструмент | Что делает | Метод API v2 |
|---|---|---|
| `cdek_list_cities` | Город по названию: код СДЭК, регион, район. Нет точного совпадения — подсказки по началу названия | `GET /location/cities`, `GET /location/suggest/cities` |
| `cdek_list_points` | ПВЗ и постаматы в городе: код, адрес, часы, наличные/карта, наложенный платёж, примерочная, макс. вес, ссылка | `GET /deliverypoints` |
| `cdek_calc` | Стоимость и сроки между городами по весу (г) и габаритам (см). Без `tariff_code` — все тарифы, дешёвые сверху; с `tariff_code` — сумма с услугами | `POST /calculator/tarifflist`, `POST /calculator/tariff` |
| `cdek_get_order` | Статус заказа и история (15 последних) по номеру накладной СДЭК, номеру заказа магазина или uuid; ссылка на трекинг | `GET /orders?cdek_number=`, `GET /orders/{uuid}` |

Город можно передать кодом (`44` — Москва, `137` — Санкт-Петербург) или названием — тогда берётся первая подсказка
СДЭК, и её полное название возвращается в ответе (поле `city` / `from_city` / `to_city`), чтобы проверить.

Данные получателя (имя, телефон, паспорт) `cdek_get_order` не отдаёт.

## Чего не умеет (и не будет)

- Создавать, менять, удалять и отменять заказы; заявки на вызов курьера; возвраты; печать накладных и ШК.
- Платежи, наложенный платёж, реестры, вебхуки.
- Нет `propose`/`apply`: запись в СДЭК — действие с деньгами, в первой версии её нет совсем.

## Ключ

Файл `~/.config/gastech-mcp/cdek.token` (0600), путь меняется `GAS_CDEK_KEY_FILE`:

```json
{"account": "...", "secure": "...", "test": true}
```

- `test: true` — тестовая среда `https://api.edu.cdek.ru/v2`, иначе боевая `https://api.cdek.ru/v2`.
  `GAS_CDEK_BASE` подменяет адрес (тесты).
- **Нет файла** — коннектор работает на песочнице СДЭК публичной тестовой учётной записью из документации
  (apidoc.cdek.ru → «Подключение к сервису»). В каждом ответе поле `"среда": "песочница: …"` — данные учебные,
  тарифы без скидок договора.
- Боевые account/secure (делает владелец или клиент): договор со СДЭК → личный кабинет lk.cdek.ru → Интеграция →
  ключи API (путь в ЛК **не проверял**). Оригинал — KeePassXC `gastech.kdbx`, группа `mcp/cdek`.
- Авторизация — OAuth `client_credentials` (`POST /oauth/token`), токен живёт 3599 с (проверено на песочнице);
  коннектор держит его в памяти процесса до истечения минус минута и прячет из ответов вместе с account/secure.

## Лимиты

Документация («Лимиты и производительность»): гарантированная обработка — 200 запросов в секунду на все методы.
Коннектор держит не больше 20 в секунду (`Throttle(20, 1)`).

## Проверено на песочнице (15.11.2026, публичная учётная запись)

- Токен: `200`, `token_type: bearer`, `expires_in: 3599`, `scope: location:all order:all payment:all`.
- `cdek_list_cities("Казань")` — код 424 (Татарстан) и два села в Кировской области.
- `cdek_list_points(137, PVZ)` — SPB1 (Лиговский пр., 50), SPB3 …
- `cdek_calc(44 → 137, 2 кг, 30×20×15)` — 17 тарифов, дешёвый 136 «Посылка склад-склад» 200 ₽, 1–2 дня.
- `cdek_calc("Москва" → "Казань", 2 кг, tariff 136)` — доставка 235 ₽, итого 282 ₽, 8–12 дней.
- `cdek_get_order("1234567890")` — `v2_order_not_found` (заказов на песочнице не создавали).

## Не проверено

- Ответ `GET /orders` с настоящим заказом: fixture `order.json` собран по схеме OpenAPI, данные выдуманные.
  Проверить на первом боевом/тестовом заказе клиента.
- Почему `total_sum` больше `delivery_sum` при страховке 0 ₽ (вероятно, НДС 20%) — по документации не сверял.
- Ссылка на трекинг `https://www.cdek.ru/ru/tracking?order_id=<номер>` — формат с сайта, не из документации API.

## Сценарий

**Интернет-магазин или кафе с доставкой + СДЭК.** Покупатель в чате спрашивает «сколько доставка до Казани и где
забрать?» — агент вызывает `cdek_calc(from_city=<склад>, to_city="Казань", weight_g=…)` и `cdek_list_points("Казань",
type="PVZ")`, отвечает ценой, сроком и тремя ближайшими ПВЗ. Покупатель спрашивает «где мой заказ?» —
`cdek_get_order(im_number=<номер заказа>)` → статус и город.

**Оценка «минут до/после» (не замерено, оценка):** ответ на «сколько доставка» через калькулятор на сайте СДЭК —
~3 мин → ответ сразу; «где заказ» (найти накладную, открыть трекинг) — ~2 мин → ответ сразу.
Замерить на первом клиенте с СДЭК.

## Подключение в harness

Запись для `portfolio-hq/integrations/servers.json` (добавить после слияния):

```json
"cdek": {
  "type": "stdio", "command": "python3",
  "args": ["{gas_pult}/src/gas_pult/connectors/cdek_mcp.py"],
  "env": {"GAS_CDEK_KEY_FILE": "{secrets}/cdek.token"},
  "auth": {"kind": "file", "file": "cdek.token", "keepass": "mcp/cdek",
           "get_key": "без файла — песочница СДЭК; боевой ключ — lk.cdek.ru → Интеграция"},
  "purpose": "СДЭК: города, ПВЗ, расчёт тарифа, статус заказа — только чтение"
}
```

Без файла ключа `mcp-install.sh` сервер пропускает (docs/CONNECTORS.md, «Запись в servers.json»). Для песочницы
положите в `cdek.token` публичные данные из документации с `"test": true`.

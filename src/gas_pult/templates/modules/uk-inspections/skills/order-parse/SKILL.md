# Предписание → пункты

1. **Источник.** Текст в сообщении, файл PDF/скан в `data/incoming/` или строка, которую внёс человек. PDF с текстовым
   слоем — читай файл; скан без текста — не угадывай: попроси человека продиктовать пункты или дать текст.
2. **Реквизиты предписания:** номер, дата, орган, дом(а), срок исполнения (общий или по пунктам), кто подписал.
   Срок не виден — вопрос человеку; без срока пункт не заводим.
3. **Пункты.** Каждое нарушение — отдельная строка: номер пункта как в предписании, суть нарушения коротко (без ФИО
   жителей), дом, срок. Текст предписания не переписываешь «своими словами» по существу — только сокращаешь.
4. **Исполнитель** — по `data/houses.csv` (ответственный инженер) или по виду работ (подрядчик из `data/contractors.csv`,
   если есть). Не очевидно — вариантом в вопросе.
5. **Черновик** — `outbox/orders-<дата>-<предписание>.csv` в формате `data/orders.csv`, статус `открыт`; папки
   `evidence/<предписание без «/»>/<пункт>/`. Вопрос AskUserQuestion: «Предписание № <n> от <дата>: N пунктов,
   срок <дата>, исполнители: … — внести в реестр?» — «Внести», «Изменить», «Не вносить».
6. «Внести» — допиши строки в `data/orders.csv` (только после ответа) и подготовь поручения исполнителям
   (`templates/task.md` → `outbox/tasks/`) — уходят пачкой после отдельного «Да» (блок напоминаний).
7. Сразу посчитай сроки навыком `order-watch`: если до срока меньше `report_days` рабочих дней (CLAUDE.md) — это вопрос
   директору уже сегодня.

# Черновик договора

1. Из сообщения клиента выпиши: вид договора, стороны, предмет, цена и порядок оплаты, сроки, особые условия.
2. Шаблон — по виду из `templates/`. Нет такого вида — скажи: «шаблона <вид> нет — пришлите шаблон юриста»; с нуля
   не пиши.
3. Стороны — из `data/parties.csv`; реквизиты — `requisites-check`. Нет стороны — «Что уточнить».
4. Заполни поля; условия, которых нет в шаблоне (особые условия клиента), — не вписывай в текст, а вынеси в
   «Вопросы юристу» в начале черновика.
5. Первая строка — «ЧЕРНОВИК — проверяет юрист». Затем «Что уточнить» и «Вопросы юристу», затем текст.
6. Файл — `outbox/docs/<дата>-договор-<контрагент>.md`; вопрос — «Передать юристу», «Изменить», «Оставить черновиком».

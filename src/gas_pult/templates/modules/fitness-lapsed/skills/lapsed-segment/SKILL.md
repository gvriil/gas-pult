# «Пропал»: отбор

1. Скрипт — рядом, только стандартная библиотека:
   `python3 .claude/skills/lapsed-segment/lapsed.py --today <сегодня> --members data/members.csv
   --visits data/visits.csv --from 14 --to 21 --min-gap 14 --freeze "12 мес.:30;6 мес.:14;3 мес.:7"`
   (числа и правила — из CLAUDE.md). В stdout — CSV: `soft` — мягкое сообщение, `call` — звонок; в stderr — пропущенные.
2. `soft` → `reminder-batch` по `templates/soft-return.md`, вопрос «Отправить пачку из N?».
3. `call` → `CALLS.md`: имя, филиал, дней без посещений, остаток заморозки; телефоны не пишем.
4. Ответ «хочу отказаться» — найди участника в выводе (`заморозка_дней`) и спроси человека: «Предложить заморозку N
   дней?» — «Предложить заморозку» / «Оформить отказ» / «Позвоню сам». N = 0 — вариант заморозки не предлагай.

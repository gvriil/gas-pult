# Отправка одобренной пачки

1. Проверь: «Да» получено на вопрос именно об этом файле `outbox/…`, и файл с тех пор не менялся. Нет — не
   отправляй, спроси заново.
2. Проверь тихие часы из CLAUDE.md. Сейчас тихие часы — не отправляй, напиши, когда отправишь, и спроси снова
   после их окончания.
3. Отправляй по одному сообщению через подключённый канал (почта — коннектор Gmail; Telegram — MCP-сервер бота
   рассылок). Ошибка на сообщении — не повторяй больше одного раза, иди дальше.
4. Перенеси пачку в `outbox/sent/<тот же файл>` и допиши внизу итог: отправлено N, ошибок K (по номерам в пачке,
   без контактов), время.
5. Коротко доложи человеку: «Отправлено N из M, ошибок K — подробности в outbox/sent/<файл>».

Канал умеет только черновики (например, почта создаёт черновики писем) — создай их и скажи человеку, что
отправить нужно из почты.

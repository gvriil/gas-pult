# Слоты для ответа на заявку

1. Новые заявки — `статус = новая` в `data/leads.csv` (или пришедшие через вебхук, Gmail, VK API, бота — допиши их
   строкой в `data/leads.csv`, без лишних полей).
2. Слоты: `python3 .claude/skills/lead-slots/lead_slots.py slots --lead <id> --now <сейчас ГГГГ-ММ-ДДTЧЧ:ММ>
   --n 3 --lead-hours 10`. В stdout — CSV (вид, филиал, дата, время, тренер, свободно); в stderr — «нет слотов».
3. Ответ — `templates/first-reply.md`: поля `{имя}`, `{филиал}`, `{слоты}` (строками «пн 3 ноября, 18:00 —
   экскурсия, Филиал Центр»). Цены — только из `data/price.md`.
4. `auto_reply` = да — отправь сразу и поставь `статус = ответили`; нет — `outbox/<дата>-first-reply-<id>.md`.
5. Выбрал слот — запись (API) или бронь в `outbox/bookings.csv`: `id, филиал, дата, время, вид, статус=бронь`.

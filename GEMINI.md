# gas-pult — брифинг для Gemini

Этот файл — контекст проекта для Gemini (загрузите его в чат или Gem; Gemini CLI читает `GEMINI.md` из корня
репозитория сам). Ваша роль: **продуктовый дизайнер и аналитик**. Вы смотрите на панель глазами пользователя,
находите, что мешает, и пишете **технические задания для Claude Code**, который вносит изменения в код. Сами вы код
в репозиторий не пишете.

Репозиторий: https://github.com/gvriil/gas-pult (публичный, лицензия PolyForm Noncommercial 1.0.0).

## Что это

gas-pult — пульт для сессий **Claude Code**, которые работают на сервере в `tmux`. Владелец ведёт несколько сессий
одновременно (по проектам) и управляет ими с телефона: видит, кто работает, кто ждёт ответа, читает ответы,
пишет и диктует задания, отвечает на вопросы Claude кнопками, слушает ответы голосом.

Два интерфейса над одним ядром:

1. **Telegram-бот** — ответы Claude приходят в чат сами; текст, голосовые, фото и файлы уходят в активную сессию.
2. **Панель** (Telegram Mini App, она же открывается в браузере) — все сессии и их состояние на одном экране.
   Вход из браузера — одноразовым кодом из Telegram, без паролей. Есть демо-режим без входа: адрес панели + `/?demo`.

## Пользователь и сценарии

- Один владелец, телефон в одной руке, часто на ходу. Главное — **за 3 секунды понять состояние всех сессий** и
  ответить в нужную, не перепутав.
- Типичный день: 3–7 сессий (разные проекты), Claude то работает, то ждёт разрешения («Do you want to proceed?
  1. Yes 2. … 3. No»), то закончил и ответил.
- Голос — основной ввод: диктовка (Whisper на сервере) и озвучка ответов («Кратко» — первые абзацы, «Целиком»).
- Иногда — с ноутбука: тогда панель в две колонки.

## Как устроена панель (экраны)

- **Сессии** — сводка «ждут ответа · работают · свободны», карточки по приоритету. На карточке: статус, папка,
  ветка, строка о последнем шаге, полоска «Контекст: N%» (> 70% — янтарная), «новый ответ», «⋯» (открыть,
  сделать активной, завершить). Ждущие ответа — янтарные, с кнопкой «Ответить». Внизу — «Новая сессия».
- **Сессия → Переписка** — все сообщения, Markdown, таблицы, код; вывод терминала и длинный код свёрнуты;
  у ответов «Кратко / Целиком / Копировать»; команды из ответа — с кнопкой «Выполнить» и результатом.
- **Сессия → Экран** — тёмный терминал (последние строки, весь — по кнопке, перенос строк — переключатель),
  вопрос Claude крупными кнопками, клавиши `1 2 3 ↑ ↓ ⏎ Esc Ctrl+C`.
- **Нижняя панель** — строка «Пишете в <сессия> · статус», поле ввода, меню (4×2), скрепка, микрофон
  (после записи: отмена · «В текст» · отправить).
- **Шапка** с вкладками уходит при прокрутке вниз и возвращается от лёгкой прокрутки вверх.
- **Интеграции** — голос (сервер или ElevenLabs), ключи API, MCP-сервисы: Notion, Gmail, Календарь, Диск, Slack,
  Linear, Jira, Figma — через коннекторы claude.ai в одно касание; GitHub, Home Assistant — по ключу; свой сервер.
- **Модели** — сессия может работать не только на Claude: OpenRouter, GLM (Z.ai), DeepSeek по ключу поставщика
  («Интеграции» → «Модели»); поставщик выбирается при «Новой сессии», меняется в меню «Модель» (перезапуск сессии).
  Механизм — Anthropic-совместимый API (`ANTHROPIC_BASE_URL`), не другой агент.
- **Связь** — 15 секунд без ответа сервера → янтарная плашка «Нет связи» и «Переподключить».

## Дизайн-система

«Тёплая бумага + терракота», ориентиры — Claude.ai, Linear, Raycast. Токены (светлая / тёмная):

| Токен | Светлая | Тёмная | Где |
|---|---|---|---|
| `--bg-canvas` | `#F6F5F0` | `#111110` | фон |
| `--bg-surface` | `#FFFFFF` | `#1A1918` | карточки |
| `--bg-subtle` | `#ECEAE3` | `#242321` | плашки, вкладки, свёрнутые логи |
| `--bg-terminal` | `#161615` | `#0C0C0B` | терминал |
| `--text-primary / secondary / muted` | `#181816 / #6E6C65 / #9E9B93` | `#F2F0E8 / #9E9B93 / #6E6C65` | текст |
| `--accent-primary` | `#C85A32` | `#E06D44` | главные кнопки |
| `--status-idle` | `#8E8C84` | `#6E6C65` | свободна (серый, **не зелёный**) |
| `--status-running` | `#2563EB` | `#60A5FA` | работает |
| `--status-approval` | `#D97706` | `#FBBF24` | ждёт ответа человека |
| `--status-success` | `#15803D` | `#4ADE80` | готов результат, «новый ответ» |
| `--status-danger` | `#DC2626` | `#F87171` | ошибка, завершение |

Правила: никаких системных эмодзи в интерфейсе (только линейные SVG-значки), никаких «немых» полосок без подписи,
никаких простыней терминала — сворачивать. Главные действия — в нижней трети экрана (под большим пальцем),
разрушительные — дальше от пальца и с подтверждением. Цифры — `tabular-nums`. Учитывать `prefers-reduced-motion`.

## Техническое устройство (кратко)

- Python, ядро — **только стандартная библиотека**. Сервер панели — `webapp.py` (HTTP + JSON API), интерфейс —
  один файл `src/gas_pult/web/index.html` (HTML + CSS + JS без сборки).
- Сессии — окна `tmux`, где запущен `claude`. Состояние читается с экрана окна (`tmux capture-pane`) и из журналов
  Claude Code (`~/.claude/projects/<папка>/*.jsonl`).
- API панели (`/api/…`): `sessions`, `meta`, `history`, `screen`, `send`, `key`, `select`, `command`, `model`,
  `new`, `close`, `active`, `upload`, `stt`, `tts`, `cmds`, `run`, `mcp*`, `providers`, `keys`, `login/*`.
- Тесты — `pytest` (66 штук), стиль — `ruff`. CI на GitHub: Linux и macOS, Python 3.11–3.14.

Известное ограничение: сессии в **одной папке** показывают общую переписку и превью — панель читает последний
журнал папки, а не журнал конкретного окна.

## Как писать задание для Claude Code

Claude Code работает лучше всего, когда задание:

1. **Начинается с цели и критерия успеха** — что пользователь должен смочь сделать и как это проверить
   («за 3 секунды видно…», «одним касанием…»).
2. **Разбито на пункты по экранам** (Сессии, Переписка, Экран, Нижняя панель, Интеграции, Десктоп) — каждый пункт
   проверяемый: что было → что должно стать.
3. **Называет ограничения**: не переписывать сервер и работу с `tmux`; новые поля API — только обратно совместимые;
   сохранить голос, озвучку, темы, демо-режим, «Экран», «Интеграции»; все тесты зелёные; токены — из таблицы выше.
4. **Предлагает фазы** — Claude Code делает фазу, проверяет тестами и скриншотами демо-режима, коммитит, затем
   следующую.
5. **Не содержит секретов** — ни токенов, ни паролей, ни адресов серверов: репозиторий публичный.

Шаблон:

```
ЦЕЛЬ: …
КРИТЕРИЙ УСПЕХА: …
ЗАДАЧИ ПО ЭКРАНАМ:
  1. <экран> — было: … → стало: …
ОГРАНИЧЕНИЯ: (см. брифинг) + …
ФАЗЫ: 1) … 2) …
КАК ПРОВЕРИТЬ: …
```

Если чего-то не знаете о коде — так и напишите в задании («проверь, как сейчас устроено X»): Claude Code сам
изучит код. Не придумывайте имена файлов и функций.

# Черновики ответов на отзывы

1. **Возьми новые отзывы** без ответа: официальный API площадки (если интеграция подключена) или файл в `data/`.
   Запиши, откуда и за какой период.
2. **Разложи**: позитив (4–5), нейтрально (3 с конкретикой), негатив (1–3, «стоп-слова» из правил блока),
   вопрос (нужен факт: размер, состав, сроки). Негатив — сразу отдельный вопрос руководителю (шаг 5).
3. **Черновик** на каждый — `outbox/reviews-<дата>.md`:

   ```markdown
   ## 1. <товар/услуга> · ★2 · <дата> · id <id отзыва>
   Отзыв: <коротко, без личных данных>
   Ответ: <2–4 предложения: спасибо → по сути → что делаем/куда обратиться>
   Метка: негатив / вопрос / позитив
   ```

   Не выдумывай факты (состав, сроки, политику возврата) — бери из `data/` или правил модуля; нет — «уточнить у
   человека» вместо ответа. Не повторяй один и тот же ответ дословно больше двух раз в пачке.
4. **Пачка** — AskUserQuestion: «Опубликовать N ответов? Позитив: a, вопросы: b. Первый: <начало ответа>» —
   варианты «Опубликовать все», «По одному», «Нет».
5. **Негатив** — отдельно и сразу: «Негативный отзыв ★<n> на <товар>: <суть в одну строку>. Ответ готов —
   опубликовать?» — «Опубликовать», «Изменить», «Не отвечать».
6. «Опубликовать» — навык `review-publish`. «По одному» — тот же вопрос на каждый ответ. «Изменить» — спроси, что
   поменять, и задай вопрос заново.

## 3. Шаги до типовых действий

Панель — на телефоне, от главного экрана. Бот — от клавиатуры меню. Простой режим — от экрана разговора.

| Действие | Панель, полный режим | Простой режим | Бот |
|---|---|---|---|
| **Новая сессия в существующей папке** | «Новая сессия» → папка → [поставщик, если готовых ≥ 2] — **2–3** | «Мои агенты» → «Подключить агента» → отрасль → агент → «Подключить» — **4–5**, только из модуля | «🆕 Новая» → папка — **2** |
| … в новой папке | «Новая сессия» → «Новая папка» → ввод имени → «Создать и открыть» → [поставщик] — **3–4 + ввод** | нет | «🆕» → «📁 Новая папка…» → ввод имени — **2 + ввод** |
| … из модуля | «Новая сессия» → «Из модуля» → модуль → «Создать и открыть» → [поставщик] — **4–5** | как выше — **4–5** | `/modules` → отрасль → модуль → «✅ Создать» — **команда + 3**; через «🆕» — **5** |
| **Ответить в сессию** | карточка → ввод → «Отправить» — **2 + ввод**; на вопрос Claude — карточка → кнопка варианта — **2** | ввод → «Отправить» — **1 + ввод**; вопрос — кнопка — **1** | в активное окно — **0 + ввод**; в другое — «🔀» → окно → ввод — **2 + ввод**; вопрос — кнопки 1/2/3 под экраном — **1** |
| **Отправить файл** | карточка → «+» → источник → выбор файла → «Отправить» — **5** | у владельца и участника кнопки нет; в пространстве тестировщика — «Мои агенты» → «Файлы сессии» → «Загрузить файл» → выбор → «Отправить» — **5** | скрепка Telegram → файл — **2** (в активное окно); в другое окно — ещё **2** |
| **Сменить модель** | карточка → меню → «Модель» → модель — **4**; второй путь: меню → «Команды» → «Модель» → модель — **5**; модель по умолчанию — «Настройки» → «Модель по умолчанию» → модель — **3** | нет | «⚡ Команды» → «🧠 Модель» → модель — **3**, только для активного окна, и меняется общая настройка (раздел 4) |
| **Закрыть сессию** | с главной: «⋯» на карточке → «Завершить сессию» → «Да» — **3**; из сессии: меню → «Завершить» → «Да» — **3** (с открытием карточки — **4**) | владелец — нет, только через полный режим; тестировщик — «Мои агенты» → «Закрыть сессию» → «Закрыть» — **3** | «📋 Окна» → окно → «⛔ Завершить» → «Да, завершить» — **4** |

**Что видно из таблицы:**
- **Бот короче панели** для ответа и файла: в нём всегда есть «активное» окно, а панель каждый раз требует открыть карточку.
- **Файл в панели — самый длинный путь** (5 шагов). Простой режим владельца и участника не умеет файлы вообще.
- **Модель:** в панели два пути одной длины ±1, в боте путь короче, но с побочным эффектом.
- **Закрыть сессию** в боте на шаг длиннее, чем в панели. Слова разные: в полном режиме «Завершить», у тестировщика
  «Закрыть сессию».

### 4.2. Несколько путей к одному внутри панели

- **Сменить сессию из переписки — 4 пути:** кнопка в шапке, «куда уйдёт» у поля ввода, меню → «Сессии», на компьютере
  ещё и боковая полоса.
- **Действия с сессией — 2 входа**, и это сознательно: «⋯» на карточке и долгое нажатие в шторке.
- **Модель — 2 пути в одном меню:** «Модель» и «Команды» → «Модель».
- **«Активная» — 2 места** (меню и «⋯»). Понятие нужно только боту. Надпись уже обсуждалась (решение за владельцем
  в HANDOFF: «Активная» → «Для бота»?).
- **Завершить — 2 места:** меню и «⋯». Полный режим и пространство тестировщика используют разные слова и разные
  маршруты (`/api/close` и `/api/space/close`).
- **«Команды из всех сессий» — 2 входа:** вкладка на главной и пункт в шторке.
- **«Обозначения» — 3 входа:** «Настройки», шторка сессий, помощник.
- **Тема — 3 строки в «Настройках»** вместо одного переключателя.

### 4.3. Мёртвое или недостижимое

- **Лист «Уровень усилий» и `/api/effort`.** До #113 лист открывался сразу после выбора модели. Теперь кнопки нет, но
  экран `sheet.effort` есть в карте помощника. Подсказка экрана `sheet.model` («Выберите модель — затем уровень
  усилий») описывает шаг, которого больше нет.
- **`ACTIONS.top` в меню действий:** обработчик есть, кнопки нет.
- **Маршруты `/api/last` и `/api/setup/cancel`:** интерфейс их не вызывает (раздел 2.3).

## 5. Что почти не используется

1 наблюдатель). Ни по одному пункту этих данных не хватает, чтобы удалять функцию. Они подсказывают только, куда
смотреть и что замерить.

**Журнал Caddy, 07.11, около 12 ч, 17 826 запросов, 6 клиентов:**

|---|---|---|

## 6. Что путает новичка

Взгляд человека, который впервые открыл панель или бота. Источник — код, тексты интерфейса и карта помощника;
опросов и записей экрана не было.

1. **Два разных «Команды».** На главной вкладка «Команды» — команды терминала из ответов Claude (выполнить на
   сервере). В меню сессии пункт «Команды» — служебные команды Claude Code (`/compact`, `/clear`…). Одно слово —
   две разные вещи на соседних экранах.
2. **«Активная».** Пункт меню и строка в «⋯» меняют только то, куда пишет бот. Человек, который бота не открывал,
   не может понять, что это. Рядом стоит «куда уйдёт» у поля ввода: эта кнопка про панель, а не про бота.
3. **Модель — в четырёх местах с разными словами:** меню → «Модель», в нём «Сменить поставщика этого чата…»,
   «Настройки» → «Модель по умолчанию», «Настройки» → «Поставщики». Плюс «Команды» → «Модель». Непонятно, какое
   из мест меняет текущий чат, а какое — все чаты.
4. **Помощник обещает несуществующий шаг.** На экране «Модель сессии» он пишет «затем уровень усилий», а такого
   шага нет с #113.
5. **«Завершить» и «Закрыть сессию»** — одно действие называется по-разному в полном режиме и в пространстве
   тестировщика. Отличие от «Удалить» объяснено, а отличие между этими двумя словами — нет.
6. **Простой режим не включить из полного напрямую.** Обратный путь есть («Выключить простой режим»), а прямой —
   только косвенно: через «Возможности», снимая галочки, или через выбор роли при первом входе.
7. **«Экран» рядом с «Перепиской».** Это терминал tmux. Новичку незачем видеть его второй вкладкой на первом месте;
   в простом режиме его нет — там это решено.
8. **Бот:**
   - команды не видны в подсказке «/»: `setMyCommands` не вызывается;
   - первое сообщение без активного окна получает отказ «Активного окна с Claude нет — выбери в 🔀 Переключить»;
   - выбор окна — в «🔀», действия с окном — в «📋», состояние — в «📊»: три кнопки про одно и то же.
9. **Настройки — 22 пункта без групп.** Важное для новичка («Уведомления», «Язык») стоит между «Сервер — pass» (убран в задаче 47) и
   «Модель по умолчанию»; тема занимает три строки.

## 8. Предложения — по пользе, самое полезное первым

Пометки:
- **убрать** — удалить пункт или код;
- **объединить** — свести несколько путей в один;
- **спрятать** — оставить, но убрать с первого экрана или выключить по умолчанию.

**Оценки** — польза для человека (удобство, меньше путаницы и ошибок), риск, трудозатраты; каждая по шкале
высокая / средняя / низкая. При равной пользе выше стоит то, что дешевле и безопаснее.

**Правило для всех пунктов:** маршруты API не удаляются (по правилам репо — «только добавлением»). Меняется
интерфейс, а маршрут остаётся.

## 9. Ограничения данных

- **Журнал Caddy** — только около 12 ч одного дня (07.11): файлы режутся по размеру, хранится 3 архива. Опрос забивает
  объём, поэтому за сутки остаётся меньше суток. Тела запросов не пишутся: видно маршрут, но не какую кнопку нажали.
  Большинство GET — фоновый опрос, а не действия человека.
- **`journalctl`** — с 22.10. Действий пользователей бот и панель туда не пишут: только запуски, ошибки и `sudo`.
- **Бот** — частот нет вообще. Переписку бота аудит не читал: в ней личные данные, и читать её задача не требовала.
- **Журнал команд** хранит последнюю отметку: запуск из бота мог перекрыться запуском из панели.
- **Люди** — фактически один владелец и три человека с ролями. Частоты отражают привычки владельца, а не «типичного
  пользователя». Для клиентов и тестировщиков данных почти нет.
- **Шаги** посчитаны по коду, а не по записи экрана. Реальное число касаний может отличаться: клавиатура, системные окна,
  прокрутка длинных списков.
- В отчёте нет адресов, доменов, Telegram ID, имён людей, кодов приглашений и путей сервера — только агрегаты и
  относительные пути репозитория.

**Ничего не удалено.** Все пункты раздела 8 — предложения; каждый выполняется отдельным PR после «да» владельца.

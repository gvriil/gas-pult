# Возврат и допродажа: отбор

1. По `data/visits.csv` для каждого клиента — последний визит (дата, филиал) и последняя мойка без детейлинга.
2. **Возврат**: дней с последнего визита — от `return_from` до `return_to` (из CLAUDE.md). Больше `return_to` —
   в список «ушли» для человека, не в пачку.
3. **Допродажа**: мойка без детейлинга за последние `upsell_hours` часов; детейлинга не было 30 дней.
4. **Убери**: `отписка = да`; нет `согласие_реклама = да`; писали меньше `min_gap_days` дней назад
   (`последнее_сообщение`, `outbox/sent/`); нет контакта для канала; дубли. Клиент в обеих пачках — только допродажа.
5. `SEGMENTS.md`: по пачкам — число по филиалам; убрано — сколько и почему (без имён).
6. Пачки — `reminder-batch`: `templates/return.md` и `templates/detailing.md`, поле `{филиал}` — филиал визита.
   Вопрос «Отправить пачку из N?» о каждой отдельно.

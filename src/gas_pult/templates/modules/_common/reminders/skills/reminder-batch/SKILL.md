# Пачка напоминаний

1. Отбери получателей по задаче (дата записи, срок оплаты) из данных клиента.
2. Убери тех, у кого нет согласия на уведомления, кто отписался, и дубли.
3. Подставь данные в шаблон, черновики — в `outbox/<дата>-<шаблон>.md` (одно сообщение — один блок).
4. Спроси AskUserQuestion: «Отправить пачку из N? Шаблон: <имя>. Первые: <имена>» — варианты «Да» / «Нет».
5. «Да» — отправь ровно эту пачку через подключённый канал и запиши итог; «Нет» — оставь черновики.

Заготовка: подробные правила дополнит отраслевой модуль.

# Отчёт ночной смены

Файл `REPORT.md` в корне папки. Человек читает его с телефона за минуту: коротко, без воды, по-русски.
Пиши по ходу смены (после каждой задачи), а не только в конце: если сессию прервут, отчёт уже есть.

## Шаблон

```markdown
# Ночная смена <дата>

Итераций: N из <лимит> · ветка: night/<дата> · коммитов: K

## Ждёт решения
- <вопрос, который задан кнопками и ещё без ответа> — что будет при «Да»

## Сделано
- [x] <задача> — <одна строка: что изменено>. Проверка: <тесты/линтер — зелёные>. Ревью: чисто.

## Не сделано
- [ ] <задача> — <почему: заблокирована / лимит / ответ «Нет»>. Что нужно, чтобы продолжить: <…>

## Заметки
- <что заметил по пути и не стал трогать: технический долг, риски, идеи> (не больше пяти пунктов)
```

## Правила

- Раздел «Ждёт решения» — первым: это главное для утра. Пусто — напиши «ничего».
- Без секретов, ключей и персональных данных — даже если встретил их в коде (напиши «секрет в <файл>», без значения).
- Утром по расписанию: закончи текущий шаг, обнови отчёт и коротко перескажи его в ответе (3–7 строк).

# Источники цифр

Данные — только из выгрузок самого клиента и его Google Таблиц через официальный коннектор. Источник и описание
колонок — в `SOURCE.md`. Файлы данных только читаешь, не правишь.

## CSV в data/

- Кодировка: UTF-8; не читается — попробуй `cp1251` (так часто сохраняет Excel и 1С).
- Разделитель: посмотри первую строку — `;` или `,`. Числа вида `1 234,56` → убери пробелы, запятую замени точкой.
- Колонки примера: `plan.csv` — дата, показатель, план; `fact.csv` — дата, показатель, факт. Даты — ГГГГ-ММ-ДД или
  ДД.ММ.ГГГГ.
- Считай стандартной библиотекой Python (`csv`) — без установки пакетов.

## Google Таблица

- Через подключённый Google Диск: найди таблицу по ссылке или названию из `SOURCE.md`, прочитай нужные листы.
- Коннектор не подключён — скажи человеку: «Подключите Google Диск: панель → Интеграции → Google Диск» и считай
  по CSV, если он есть.

## Выгрузка 1С

- Берёшь самый свежий файл в `data/` по времени изменения (`ls -t`). Файлу больше суток — предупреди в сводке.
- CSV — как выше. XLSX: если есть `openpyxl` — читай им; нет — `libreoffice --headless --convert-to csv`;
  нет и этого — попроси человека сохранить отчёт в CSV.
- 1С пишет заголовки отчёта в первые строки (название, период) — пропусти их до строки с названиями колонок.
  Итоговые строки («Итого») в расчёт не бери.
- Колонки 1С один раз опиши в `SOURCE.md`: какая — дата, показатель (номенклатура, подразделение), сумма.

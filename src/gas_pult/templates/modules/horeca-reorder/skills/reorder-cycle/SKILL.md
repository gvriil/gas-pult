# Цикл заказов

1. По `data/orders.csv` — даты заказов каждого ресторана за последние 60 дней.
2. **Цикл**: медиана интервалов между соседними заказами (дней). Если ресторан заказывает по дням недели (две и
   больше недели подряд в одни и те же дни) — цикл «по дням недели: пн, пт».
3. **Ожидаемый заказ**: последний заказ + цикл (или ближайший обычный день недели). Ресторан — кандидат, если
   ожидаемая дата доставки — завтра или уже прошла, а заказа на неё нет.
4. Исключи: отписку, нет согласия на уведомления, стоп-лист, заказ уже есть, напоминали сегодня (`outbox/sent/`).
5. **Обычный набор**: позиции, которые были в 2 из 3 последних заказов, с медианным количеством.
6. `CYCLES.md` — таблица: ресторан, цикл, последний заказ, ожидаемый, кандидат/нет, почему.

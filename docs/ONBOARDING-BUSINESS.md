# Подключить другой бизнес

Что нужно, чтобы пульт заработал у другой компании, сколько это стоит и занимает, и что для этого допилить в коде.
Состояние — на 01.11.2026 (после волны «к показу 03.11»). Цены — ориентиры, сверять перед договором.

## Коротко

**Одна установка пульта = один бизнес.** У бизнеса свой сервер или свой пользователь Linux на общем сервере, свой
Telegram-бот, свой аккаунт Claude, свои люди и папки. Несколько бизнесов в одном процессе пульт сейчас не
держит, и так задумано: «Выполнить» работает от имени пользователя сервера, и изоляция по пользователям Linux
надёжнее любой проверки внутри кода.

Подключение «под ключ» занимает 2–4 часа нашей работы плюс 30–60 минут владельца бизнеса: входы и ключи — только
его руками.

## Что нужно

| Что | Зачем | Кто делает | Время |
|---|---|---|---|
| **Сервер** — VPS от 2 vCPU, 4 ГБ памяти, 40 ГБ диска; Ubuntu 22.04+ (или Mac) | на нём живут сессии Claude, tmux, пульт | мы; аренда — на бизнес | 30 мин |
| Если есть голос «на сервере» (Piper + Whisper) | распознавание и озвучка без внешних сервисов | — | +2 ГБ памяти, +1 ГБ диска |
| **Отдельный пользователь Linux** на бизнес | «Выполнить» и сессии — с правами только этого пользователя | мы | 10 мин |
| **Telegram-бот** (@BotFather → `/newbot`) | уведомления, ответы, голос, кнопка «Панель» | владелец бизнеса (бот — его) или мы с передачей | 5 мин |
| **Аккаунт Claude** — подписка (вход `claude` → `/login` на сервере) или ключ API | модель, которая работает | владелец бизнеса: вход — только его руками | 10 мин |
| Или другой поставщик модели — OpenRouter, GLM (Z.ai), DeepSeek | дешевле; без своей подписки Claude | ключ — владелец; в панели «Настройки» → поставщик | 5 мин |
| **Домен или поддомен + HTTPS** (Caddy, Let's Encrypt) | панель в браузере и Mini App в Telegram | мы; DNS — у владельца домена | 30–60 мин |
| **Люди и роли** | кто ещё работает с пультом | люди сами жмут «Войти через Telegram», владелец выдаёт роль кнопкой | 2 мин на человека |
| **Папки проектов** («пространства») | у каждого направления — своя папка с `CLAUDE.md`: контекст, правила, документы | мы вместе с бизнесом | 30–90 мин на пространство |
| **Интеграции** (почта, календарь, Notion, CRM, 1С и т. п.) | чтобы агент работал с данными бизнеса | панель → «Интеграции»; входы — владелец | 15–60 мин на сервис |

### Люди и роли

| Роль | Что может |
|---|---|
| Владелец (`owners` в `config.toml`) | всё: сессии, «Выполнить», ключи, интеграции, люди |
| Участник | писать в сессии, отвечать на вопросы Claude, команды, модель, новые сессии, файлы; без «Выполнить» и ключей |
| Наблюдатель | только смотреть |

Как человеку войти: панель → «Войти через Telegram» → Start в боте → владельцу приходит запрос → «Участник» или
«Наблюдатель» → человек ещё раз жмёт «Войти». Подробно — [MINI_APP.md](MINI_APP.md#вход-и-люди--по-шагам).

### Данные: где что лежит

| Что | Где | Кому видно |
|---|---|---|
| Переписка с Claude | `~/.claude/projects/…` пользователя сервера (журналы Claude Code) | всем, у кого есть доступ к пульту |
| Настройки пульта, токен бота | `~/.config/gas-pult/` (0600) | только пользователь сервера |
| Люди, входы, команды, сводка | `~/.local/share/gas-pult/` (0600) | только пользователь сервера |
| Ключи поставщиков и сервисов | на сервере, наружу не отдаются | — |
| Документы бизнеса | папки проектов на сервере (и интеграции) | Claude и люди с доступом к пульту |

Перед подключением нужно договориться с бизнесом: какие данные кладём на сервер, кто администратор сервера,
как делаются бэкапы (сейчас — средствами хостинга, в пульте их нет) и что происходит с данными при отключении.

## Стоимость в месяц (ориентир)

| Статья | Сколько | Примечание |
|---|---|---|
| Сервер | €8–25 | 2–4 vCPU, 4–8 ГБ; больше — если голос на сервере и 5+ сессий одновременно |
| Модель: подписка Claude | $20–200 на человека, который ставит задачи агенту | Pro — для лёгкой работы, Max — для ежедневной; лимиты — у Anthropic |
| Модель: другой поставщик | $5–50 при оплате по факту | OpenRouter, GLM, DeepSeek; качество ниже Claude на сложных задачах |
| Голос ElevenLabs (по желанию) | $5–22 | без него — бесплатные голоса на сервере |
| Домен | ~$1 (≈ $10–15 в год) | можно поддомен бизнеса |
| Наша работа | подключение — разово; сопровождение — по договорённости | |

## Порядок подключения

1. Договориться о данных и доступах; завести сервер (или пользователя на нашем) и домен.
2. Владелец бизнеса создаёт бота у @BotFather и передаёт токен **не в чат** — в менеджер паролей или через
   `gas-pult init` при нём.
3. Установка: `install.sh` (пакет, служба, бот), `gas-pult doctor` — проверка.
4. Владелец входит в Claude на сервере (`claude` → `/login`) или вводит ключ поставщика в панели.
5. Панель на домене: Caddy + HTTPS ([MINI_APP.md](MINI_APP.md)), кнопка «📱 Панель» в боте.
6. Пространства: папки с `CLAUDE.md` под направления бизнеса — правила, шаблоны документов, ссылки на источники.
7. Интеграции, которые нужны в первую неделю (почта, календарь, таблицы).
8. Люди: каждый входит сам, владелец выдаёт роль.
9. Неделя сопровождения: что не понятно, какие кнопки нужны (`commands` в `config.toml` — свои кнопки).

По важности для второго бизнеса. Отдельные PR, в очередь — по решению владельца.

| # | Что | Почему | Объём |
|---|---|---|---|
| 1 | **Доступ участника по папкам** | сейчас участник видит и пишет во все сессии сервера; бизнесу нужно «бухгалтер видит только бухгалтерию» | `people.json` → список папок; фильтр в `/api/sessions` и боте; 1–2 дня |

| 3 | **Журнал действий людей** | кто что отправил, выполнил, завершил — для бизнеса это требование, сейчас только логи служб | файл-журнал на сервере + экран в «Настройках»; 1 день |
| 4 | **Создать пространство из панели** | новая папка с шаблоном `CLAUDE.md` сейчас — только «📁 Новая папка…» в боте, без шаблона | шторка «Новое пространство»: имя, шаблон, правила; 1 день |

| 6 | **Утренняя сводка без GitHub** | источник PR — GitHub владельца; бизнесу нужны задачи (Linear, CRM), почта, сроки | источники сводки как подключаемые модули; 1–2 дня |
| 7 | **Учёт расхода модели** | не видно, сколько стоит работа агентов по людям и направлениям | сбор из журналов Claude Code и счетов поставщиков; 2 дня |
| 8 | **Бэкап и выгрузка** | переписка и настройки бизнеса — на одном сервере | `gas-pult backup` (архив данных, папок и журналов) + восстановление; 1 день |
| 9 | **Язык интерфейса** | только русский | вынести строки, английский — вторым; 2–3 дня |
| 10 | **Несколько бизнесов на одном сервере** | сейчас — отдельный пользователь Linux на каждый (работает уже сейчас) | инструкция и проверка `gas-pult doctor`: свой сокет tmux (`GAS_PULT_TMUX_SOCKET`), свои `GAS_PULT_DATA_DIR` и `GAS_PULT_CONFIG_DIR`, свой порт панели; 0,5 дня |

Без пунктов 1–3 пульт годится бизнесу, где с агентами работает **сам владелец** и 1–2 доверенных человека. Для
команды с разными зонами ответственности нужны пункты 1–3.

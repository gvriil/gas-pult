# Соблюдение условий поставщиков моделей

Пульт сам не продаёт и не перепродаёт доступ к моделям. Он передаёт сообщения в сессии Claude Code и других
моделей, которые работают на сервере владельца, — значит, на сервере действуют условия каждого поставщика.
Здесь — наша политика, официальные страницы поставщиков и чек-лист владельца.

Сверено с официальными страницами **01.11.2026**. Условия поставщиков меняются — сверяйте перед подключением
нового человека, сервера или поставщика. Текст условий для людей пульта — [`docs/TERMS.md`](TERMS.md)
(черновик, на проверку юристу).

## Политика

1. **У каждого человека — свой аккаунт или ключ поставщика.** Одна подписка Claude (Pro, Max) — для одного
   человека: она не делится на нескольких людей и не перепродаётся. Ключи API — свои у каждого, кто работает
   с моделью, или ключ организации по коммерческим условиям поставщика, если они это разрешают.
2. **Страны и поставщики — только по их спискам поддерживаемых регионов.** Человек работает с моделью, только
   если страна, где он находится, есть в списке поставщика (ссылки ниже). Страна не в списке — значит, не
   поддерживается: такой человек с этой моделью не работает. Трафика к моделям из неподдерживаемых стран
   (включая Россию) быть не должно.
3. **Сервер и его выход в интернет — только в поддерживаемой стране.** Сервер пульта и адрес, с которого он
   ходит к API моделей, — в стране из списка поставщика (у нас — Нидерланды). Никаких VPN, прокси и выходов
   через неподдерживаемую страну, никакого обхода ограничений.
4. **Пользовательские соглашения не нарушаем.** Каждый человек пульта при первом входе принимает условия
   использования ([`TERMS.md`](TERMS.md)): он сам отвечает за соблюдение правил поставщиков и законов, а владелец
   вправе в любой момент прекратить доступ. Согласие с версией и датой хранится на сервере.

## Как пульт применяет списки стран

Проверка — **по спискам разрешённых стран** (allowlist), а не по списку запрещённых: страны нет в списке
поставщика — сервис для неё недоступен. В коде — `src/gas_pult/models.py`:

| Профиль | Список | Откуда |
|---|---|---|
| «Claude» | `ANTHROPIC` — **все 185 стран** страницы Anthropic и территории стран из списка («Territories and dependencies of a listed country are also supported», например Пуэрто-Рико) | [anthropic.com/supported-countries](https://www.anthropic.com/supported-countries), сверено 01.11.2026 (на странице — «действует с 12.11.2026») |
| «OpenRouter» | тот же список Anthropic: своего списка у OpenRouter нет, по умолчанию модели — Anthropic. Списки [OpenAI](https://developers.openai.com/api/docs/supported-countries) и [Gemini](https://ai.google.dev/gemini-api/docs/available-regions) шире, поэтому для их моделей через OpenRouter список Anthropic строже, а не мягче | — |
| «GLM (Z.ai)», «DeepSeek» | списков нет: запрещены санкционные страны `RU BY KP IR SY CU` (Z.ai прямо называет Иран, КНДР, Кубу, Крым, Донецкую и Запорожскую области) | условия Z.ai (раздел X), DeepSeek (экспорт и санкции) |

Ограничения проверки по коду страны: Anthropic поддерживает Украину **кроме** Крыма, Донецкой, Херсонской,
Луганской и Запорожской областей, Z.ai запрещает Крым, Донецкую и Запорожскую области — по коду страны (UA)
их не отличить. Это остаётся на условиях использования (`TERMS.md`) и на решении владельца.

`models.allowed(profile, countries)` — поставщик разрешён, только если он разрешён для **каждой** страны набора.
Пустой набор (страна неизвестна) — не разрешено ничего. Списки сверяются вручную (раз в квартал и при изменении
страниц поставщиков) — дата сверки в комментарии в коде.

## Страна человека

Страна человека определяется по трём признакам (`src/gas_pult/country.py`):

1. **Выбор.** При первом входе, сразу после условий использования, человек сам выбирает страну: в боте —
   кнопками частых стран или кодом из двух букв, в панели — экран «Из какой страны вы работаете?». До выбора
   бот спрашивает страну на любое действие, а API панели отвечает `403 {"code": "country"}`. Поменять — панель →
   «Настройки» → «Страна».
2. **Телефон.** В боте — кнопка «📱 Поделиться номером» (`request_contact`). Принимается только свой контакт
   (`contact.user_id` — тот, кто его прислал). Берём код страны номера (`phone_country`: +7 6xx/7xx — KZ, иначе
   RU; +1 — «US/CA», для проверки — обе). **Номер не хранится**: только `HMAC-SHA256(соль установки, номер)` и код
   страны. Соль — `<data>/country_salt` (0600, создаётся один раз, в git не попадает). В панели номер не
   подтверждается — там подсказка «подтвердите номер в боте» и ссылка `t.me/<бот>?start=phone`.
3. **IP.** При каждом входе в панель (вход через Telegram, вход кодом) и не реже раза в 10 минут на запросах
   (Mini App подписывает каждый запрос — проверка на первом) — страна адреса клиента по **локальной** базе
   [db-ip lite](https://db-ip.com/db/lite.php) (CSV, IPv4 и IPv6), без внешних запросов с данными человека.
   Адрес клиента — `X-Forwarded-For` (последний адрес, его дописал наш прокси) или `X-Real-IP`, только если запрос
   пришёл с `127.0.0.1`/`::1` (Caddy, cloudflared); иначе — адрес соединения. **IP не хранится** — только код
   страны и время. Базы нет или адреса в ней нет — признак «нет данных»: по нему не блокируем, владелец видит
   отметку в «Людях». **В боте IP недоступен** — Telegram не передаёт ботам адреса пользователей.

Что доступно — ровно то, что поставщик разрешает **для всех стран** из признаков и для страны сервера
(`region` в config.toml). Признаки расходятся (выбрал NL, номер +7, IP RU) — доступно только пересечение, а
владельцам приходит одна строка: имя или ID человека и коды стран (без номера и IP); в «Людях» панели и бота —
пометка «признаки расходятся». Отказ — ровно «Этот сервис недоступен в вашей стране по условиям поставщика»,
без подсказок, как его обойти.

Где проверяется: новая сессия, перезапуск остановленной, смена поставщика, текст и ответы в сессию (панель и
бот), список моделей в панели (недоступные — с замком и отказом), цепочка запасных — по странам того, кто
открыл окно (метка окна tmux `@gas_pult_by`), иначе первого владельца.

Хранение: у человека из `people.json` — поле `country: {chosen, phone_cc, phone_hash, phone_at, ip_cc, ip_at,
mismatch}`; у владельцев — тем же видом в `<data>/countries.json` (0600), рядом с `terms.json`. Отключили
человека — его страна удаляется вместе с записью.

**База GeoIP** загружается только по команде владельца: `gas-pult geoip update` скачивает
`https://download.db-ip.com/free/dbip-country-lite-ГГГГ-ММ.csv.gz` в `<data>/geoip/` (файла этого месяца ещё нет —
берёт прошлый); `gas-pult geoip status [IP…]` — есть ли база и что она отвечает. Панель подхватывает новый файл
сама. Обновлять раз в месяц. Лицензия базы — [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/):
«IP Geolocation by DB-IP» (https://db-ip.com) — подпись стоит в панели рядом с отметкой страны по IP.

## Каналы: MAX, VK и другие российские

Подключение каналов для России (MAX, VK) — **только с поставщиком модели, который разрешён для этого региона.
Claude (Anthropic) для них не используется:** России нет в списке поддерживаемых стран Anthropic, а трафик к модели
из неподдерживаемой страны недопустим, даже если сервер стоит в Нидерландах. То же — для любой модели, у
поставщика которой страны пользователя канала нет в списке. Какие каналы есть и с какими поставщиками — в
[`docs/CHANNELS.md`](CHANNELS.md) (колонка о регионе и разрешённом поставщике).

## Голоса: лицензии

Голоса Silero (`gas-pult voices install xenia` и др.) — лицензия [CC BY-NC-SA 4.0](https://github.com/snakers4/silero-models/blob/master/LICENSE):
только некоммерческое использование. В пульте их видит и выбирает **только владелец и только при
`personal_voices = true`** в `config.toml` — для себя лично; участникам, наблюдателям и озвучке ответов для них они
скрыты (вместо Silero — Piper). В установках для клиентов и любых коммерческих — `personal_voices = false`
(по умолчанию): голоса скрыты, даже если установлены. Piper (голоса rhasspy) и ElevenLabs — по их условиям.

## Чек-лист владельца

- [ ] **Сервер — в поддерживаемой стране.** Пульт и сессии работают на сервере в стране из списков поставщиков
  (у нас — Нидерланды).
- [ ] **Выход в интернет — там же.** Запросы к API моделей уходят с адреса сервера в этой стране: без VPN-выхода,
  прокси или туннеля через неподдерживаемую страну. Проверка с сервера: `curl -s https://ipinfo.io/country`
  (должна быть страна из списка). VPN на сервере, если он есть, — только для входящих подключений, не для выхода
  к моделям.
- [ ] **У каждого человека — свой вход или ключ.** Участник пульта работает в Claude Code под **своим** аккаунтом
  Claude или со **своим** ключом поставщика. В пульте это поддерживается так: у каждого человека — своя папка
  Claude (свои вход и настройки Claude Code), подписка владельца другим не передаётся.
- [ ] **Подписку не делим и не перепродаём.** Одна подписка Claude — один человек. Доступ к пульту не продаётся
  как доступ к моделям.
- [ ] **Человек — из поддерживаемой страны.** Перед тем как дать роль, уточните, откуда человек будет работать
  и с какими моделями; страна не в списке поставщика — с этим поставщиком он не работает. Пульт проверяет это
  сам по трём признакам (раздел «Страна человека»): в «Людях» — страна, код номера и страна по IP; пометка
  «признаки расходятся» — повод разобраться.
- [ ] **База стран по IP загружена.** `gas-pult geoip update` на сервере, раз в месяц. Без неё признак IP — «нет
  данных» (в «Людях» — отметка).
- [ ] **Условия приняты.** Каждый человек нажал «Принимаю» (панель → «Настройки» → «Люди»: «условия приняты»
  и дата). Без этого пульт ничего, кроме условий, не показывает.
- [ ] **Нарушение — отключить.** Панель → «Настройки» → «Люди» → человек → «Отключить» (или в боте ⚙️ Настройки →
  👥 Люди → «⛔ Отключить»). Доступ прекращается сразу.
- [ ] **Сверка раз в квартал** — ссылки этой страницы: списки стран и условия меняются.

## Как это устроено в коде

- Версия и короткий текст условий — `src/gas_pult/terms.py` (`VERSION`); полный текст — [`TERMS.md`](TERMS.md).
  Поменяли смысл условий — поднимите `VERSION`: бот и панель спросят согласие у всех заново.
- Согласие: `People.accept(uid, version)` / `People.accepted(uid, version)` (`people.py`). У человека из
  `people.json` — поле `terms: {"version", "at"}` в его записи; владельцев в `people.json` нет, их согласие —
  в `terms.json` рядом (0600).
- Бот: до согласия на любое действие — текст условий и «✅ Принимаю»; вход в панель (`/start login_…`) не
  задерживается. Панель: `GET /api/terms`, `POST /api/terms/accept`; остальное API до согласия отвечает
  `403 {"code": "terms"}`, `/api/meta` — поле `terms: {version, accepted}`.

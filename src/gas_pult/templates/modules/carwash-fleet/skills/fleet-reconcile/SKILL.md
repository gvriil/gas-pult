# Сверка моек автопарков

Скрипт — рядом, только стандартная библиотека:

```
python3 .claude/skills/fleet-reconcile/fleet_check.py --contracts data/fleet_contracts.csv \
  --washes data/fleet_washes.csv --month 2026-10 --out outbox/fleet-2026-10.csv
```

По каждому договору: `моек`, `лимит`, `в_лимите`, `сверх`, `к_счёту` (в лимите × цена), `сверх_сумма_вопрос`
(сверх × цена_сверх — только если человек решит выставить), `при_стопе`, `по_филиалам`. Чужие номера — в stderr.

1. Дата выгрузки моек старше суток — предупреди в сводке.
2. `FLEET.md`: таблица по договорам, чужие номера, мойки при стопе.
3. Вопросы: сверх лимита — по каждому договору («Выставить сверх лимита», «Не выставлять», «Спросить клиента»);
   чужой номер — «Чей автомобиль <номер> (<филиал>, <дата>)?» — «Добавить в договор <…>», «Розница», «Разобраться».
   Решения — в `outbox/fleet-decisions-<месяц>.csv`, чтобы счёт их учёл.
4. В середине месяца лимит выбран на 80 % и больше — строка в сводке: «<контрагент>: лимит почти выбран (N из M)».

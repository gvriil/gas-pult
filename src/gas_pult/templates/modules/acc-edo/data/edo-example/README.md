# Пример выгрузки из кабинета оператора ЭДО

Выдуманный и упрощённый: два XML по мотивам формата ФНС для клиента 1 (ИНН и КПП — нули). УПД № 12 совпадает с
первичкой `data/primary-example/1/2026-10.csv`, в акте № 7 сумма намеренно другая — для показа сверки.

Настоящие входящие кладут в `inbox/<клиент-id>/` (папку создайте сами; в git её не коммитят): XML формата ФНС,
PDF-образ, файл подписи рядом. Или их скачивает агент, если подключён API оператора (только чтение).

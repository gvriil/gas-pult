# Черновик претензии

**ЧЕРНОВИК — проверяет юрист.** Агент не оценивает перспективы спора и не выбирает правовую позицию.

1. Шаблон — `templates/claim.md` (или шаблон юриста клиента). Нет — скажи; не сочиняй.
2. Собери факты только из документов клиента: договор (номер, дата, пункт об оплате/качестве и о претензионном
   порядке), документы отгрузки (УПД, акты), оплаты, переписка. Каждому факту — ссылка на документ.
3. Расчёт: основной долг по документам; неустойка/проценты — только если ставка есть в договоре (пункт) или
   юрист сказал считать по ст. 395 ГК РФ — тогда таблица периодов, ставку ключевую не выдумывай: «ставку подставит
   юрист» или из данных.
4. Срок ответа — из договора; нет в договоре — пометка для юриста: «по умолчанию для арбитражных споров —
   30 календарных дней (ч. 5 ст. 4 АПК РФ), проверить».
5. Файл — `outbox/docs/<дата>-претензия-<контрагент>.md`, первая строка — пометка о черновике. Вопрос: «Претензия
   <контрагент> на <сумма> ₽ готова (черновик). Что дальше?» — «Передать юристу», «Изменить», «Оставить».
   Отправка контрагенту — только после проверки юристом и отдельного «Да».

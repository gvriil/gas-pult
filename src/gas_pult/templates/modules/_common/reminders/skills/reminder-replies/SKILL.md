# Ответы на напоминания

Разложи ответы по видам и запиши в `outbox/replies-<дата>.md`:

| Ответ | Что делаешь сам | Что решает человек |
|---|---|---|
| «Подтверждаю», «буду», «ок» | отметь подтверждение в черновике изменений | — |
| «Отпишите», «не пишите» | отметь отписку, больше не включай в пачки | — |
| Перенос, отмена | ничего не меняй | вопрос: «<Имя> просит перенести на <дата> — согласовать?» («Да» / «Предложить другое время» / «Нет») |
| Спор о сумме, жалоба, грубость | ничего не отвечай | вопрос с кратким пересказом, без цитаты личных данных |
| Непонятно | — | список «непонятные: N» в сводке |

Ответ клиенту на перенос или спор — черновиком и только после «Да» (как пачка из одного сообщения).
Изменения в данных клиента не вносишь сам — готовишь `outbox/changes-<дата>.csv` для человека или учётной системы.

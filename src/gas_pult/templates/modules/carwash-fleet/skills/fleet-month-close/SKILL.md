# Закрытие месяца по автопаркам

1. Сегодня — последний рабочий день месяца? `python3 .claude/skills/workdays/workdays.py is <дата>` для сегодня и
   следующих дней до конца месяца: рабочих после сегодня нет — закрываем. Человек попросил раньше — закрываем по его слову.
2. Сверка — `fleet_check.py` за месяц; решения о сверх лимита — `outbox/fleet-decisions-<месяц>.csv`. Нет решения по
   договору со сверх лимита — сначала вопрос, документы по этому договору не делаем.
3. По каждому договору с мойками — навык `document-draft`: `templates/invoice.md` и `templates/act.md`, реестр моек
   (дата, госномер, филиал, услуга) — приложением. Реквизиты — `requisites-check`. Договор под стопом — документы
   делаем (услуги оказаны), в вопросе отметка «под стопом».
4. Срок оплаты = дата документа + `отсрочка_дн`. Строки для дебиторки — `outbox/settlements-new.csv` (контрагент,
   документ, дата, сумма, оплачено 0, срок).
5. Вопрос: «Счета и акты за <месяц> готовы: N договоров на <сумма> ₽. Первые: …» — «Отправить», «Изменить»,
   «Оставить черновиком». «Отправить» — по одному письму бухгалтерии контрагента (`email_бухгалтерии`) через
   подключённую почту; нет почты — файлы для ручной отправки.

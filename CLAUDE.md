# gas-pult — правила для Claude Code

Telegram-пульт и панель для сессий Claude Code в tmux. Интерфейс, комментарии и коммиты — по-русски.

## Перед работой
- Состояние и очередь — `HANDOFF.md`; правила вклада — `CONTRIBUTING.md`; устройство — `docs/ARCHITECTURE.md`;
  панель по шагам — `docs/MINI_APP.md`; постановка задач — `GEMINI.md`.
- Если рядом есть `CLAUDE.local.md` (в git не попадает) — там устройство конкретного сервера: адреса, службы, что
  доступно с этой машины и как проверять доступ. Прочитать **до** выводов о «поломке».

## Правила
- Ядро — только стандартная библиотека Python. Интерфейс панели — один файл `src/gas_pult/web/index.html` без сборки.
- Сервер и работу с tmux не переписывать; новые поля API — только добавлением.
- Проверка: `ruff check .` и `pytest`; интерфейс — демо `gas-pult webapp --port 8797` → `/?demo` (параметры —
  в CONTRIBUTING), ширина 390 и 1366 px, светлая и тёмная тема, консоль браузера без ошибок.
- Цвета — токены из начала `<style>`; значки — `ic("имя")`; системных эмодзи в интерфейсе нет.
- `main` — только через пулл-реквест; работа — в `feature/*` и `fix/*`. Заметное — в `CHANGELOG.md` и `whatsnew.json`.
- Репозиторий публичный: никаких токенов, ключей, Telegram ID, адресов серверов и личных путей — ни в коде, ни в
  тестах, ни в коммитах.
- Кнопка «▶️ Выполнить» в пульте выполняет команду на сервере пульта. Команды для другой машины (Mac, гипервизор)
  давайте строкой в тексте, не блоком кода.
- Сессия может работать не на Claude (OpenRouter, GLM, DeepSeek — `models.py`): правила те же.

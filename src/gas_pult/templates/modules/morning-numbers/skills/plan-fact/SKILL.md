# План/факт: расчёт и формат

## Расчёт

Для каждого показателя:

- **Вчера** — последняя дата, за которую есть факт (обычно вчера; если позже — напиши, за какую дату).
- **С начала месяца (МТД)** — сумма с 1-го числа по эту дату. Для средних (средний чек, конверсия) — не сумма,
  а пересчёт: средний чек МТД = выручка МТД / заказы МТД.
- **Отклонение** = факт − план (в единицах показателя) и (факт − план) / план × 100 % (одна цифра после запятой).
- **Хорошо или плохо:** для «обратных» показателей (возвраты, расходы, брак, просрочка) рост — плохо. Отмечай
  знаком по смыслу: ▲ лучше плана, ▼ хуже плана.
- План 0 или нет плана — отклонение в % не считай, напиши «нет плана».

## Топ-3

Отклонения за вчера по модулю %, только больше порога из CLAUDE.md, сначала «хуже плана». Нет ни одного — «всё
в пределах плана».

## SUMMARY.md

```markdown
# Цифры за <дата> · ООО «…»

| Показатель | План | Факт | Откл. | Откл. % | МТД план | МТД факт | МТД % |
|---|---:|---:|---:|---:|---:|---:|---:|

## Топ-3 отклонения
1. ▼ Возвраты: 19 600 ₽ при плане 12 000 ₽ (+63,3 %)
…
```

Числа — с пробелом между разрядами (431 200), рубли — «₽».

# Фото и акты по пунктам предписаний

Папка пункта — `evidence/<предписание>/<пункт>/` (в номере предписания «/» заменяется на «-»): фото «до» и «после»
с датой, акты выполненных работ, акты подрядчиков, переписка. Исполнитель кладёт сюда файлы сам или присылает их в
сессию — агент раскладывает по папкам. Пример: `evidence/П-0-2026/1/` — пункт 1 примерного предписания.

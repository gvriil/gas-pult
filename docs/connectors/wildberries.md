# Wildberries — коннектор пульта

Код — `src/gas_pult/connectors/wildberries_mcp.py`, тесты — `tests/test_wildberries_mcp.py`, контракт —
`docs/CONNECTORS.md`. Документация WB API — https://dev.wildberries.ru/openapi/api-information. Спецификации OpenAPI,
по которым сделан коннектор (скачаны 18.11.2026):
https://dev.wildberries.ru/api/swagger/yaml/ru/09-communications.yaml (отзывы, вопросы),
https://dev.wildberries.ru/api/swagger/yaml/ru/02-items.yaml (цены),
https://dev.wildberries.ru/api/swagger/yaml/ru/12-reports.yaml (заказы).

**Статус: каркас, не проверено на песочнице.** Ответы в `tests/fixtures/wildberries/` собраны по примерам из
спецификаций WB, тексты выдуманные. С тестовым токеном — перезаписать их ответами песочницы.

## Что умеет

| Инструмент | Что делает | Метод WB API | Песочница |
|---|---|---|---|
| `wildberries_list_feedbacks` | Отзывы: оценка, текст (с «плюсами» и «минусами»), фото/видео, товар, ответ продавца. По умолчанию — ждущие ответа, свежие сверху; фильтр по артикулу и дате | `GET feedbacks-api /api/v1/feedbacks` | есть |
| `wildberries_list_questions` | Вопросы покупателей о товарах; по умолчанию — без ответа | `GET feedbacks-api /api/v1/questions` | есть |
| `wildberries_list_prices` | Цена, скидка продавца, цена со скидкой, цена с WB Клубом; разные цены по размерам — списком | `GET discounts-prices-api /api/v2/list/goods/filter` | есть |
| `wildberries_list_orders` | Заказы с даты (время Москвы): товар, склад, регион, цена, отмена; итоги — число, отмены, сумма | `GET statistics-api /api/v1/supplier/orders` | **нет** |
| `wildberries_propose_feedback_answer` | Черновик ответа на отзыв. Сам не публикует | — | — |
| `wildberries_propose_question_answer` | Черновик ответа на вопрос. Сам не публикует | — | — |
| `wildberries_apply` | Публикует подтверждённый человеком черновик: `POST /api/v1/feedbacks/answer` или `PATCH /api/v1/questions` | см. слева | есть |

Имя покупателя из отзыва коннектор не отдаёт (персональные данные; для ответа не нужно). Ссылка на товар
`https://www.wildberries.ru/catalog/<nmId>/detail.aspx` — формат с сайта WB, не из документации API.

## Чего не умеет (и не будет без отдельного решения)

- Менять цены, скидки, участие в акциях; создавать и менять карточки; поставки; FBS-заказы; продвижение.
- Возвраты, чат с покупателями, финансы, документы, управление пользователями.
- Остатки на складах WB (FBO): старый метод `/api/v1/supplier/stocks` из документации убран, теперь —
  асинхронный отчёт `/api/v1/warehouse_remains` (задача → статус → выгрузка). Кандидат на следующую версию
  (модуль `wb-ozon-stock`).
- Редактировать уже отправленный ответ (WB разрешает один раз за 60 дней) — сначала проверить ответ в черновике.

## Ключ

Файл `~/.config/gastech-mcp/wildberries.token` (0600), токен одной строкой. Путь меняется
`GAS_WILDBERRIES_KEY_FILE`. Оригинал — KeePassXC `gastech.kdbx`, группа `mcp/wildberries`.

Как получить (делает владелец или продавец; по документации WB, раздел «Авторизация»):
1. Личный кабинет продавца → **Интеграции по API** (https://seller.wildberries.ru/api-integrations).
2. **+ Создать токен** → вкладка «Для интеграции вручную».
3. Тип токена:
   - **Тестовый** — для песочницы (тестовые данные, реальные недоступны). С него начинаем.
   - **Персональный** — боевой, для своей системы на своём сервере. Передавать третьим лицам и облачным сервисам
     нельзя (условия WB) — для клиента токен создаёт и хранит сам клиент на своём сервере.
   - **Базовый** — ограниченный: отзывы 5 запросов в час, статистика 1 раз в 3 часа. Для пульта мало.
4. Категории — только нужные: **Вопросы и отзывы**, **Цены и скидки**, **Статистика**. Уровень — **Только
   чтение**, если ответы на отзывы не нужны.
5. Токен живёт 180 дней — поставить напоминание о замене.

Среда выбирается сама: у тестового токена в полезной нагрузке `t: true` → адреса `*-api-sandbox.wildberries.ru`,
иначе боевые. Переопределить — `GAS_WILDBERRIES_ENV=sandbox|prod`; `GAS_WILDBERRIES_BASE` — один адрес для всех
категорий (тесты). Токен в заголовке `Authorization` без слова `Bearer` (схема `HeaderApiKey` в спецификации).

Запись (ответы покупателям) выключена, пока не задано `GAS_WILDBERRIES_WRITE=1`, и каждый ответ — только после
подтверждения человека (`propose` → кнопка «Да» в панели → `apply`).

## Лимиты (документация WB, на профиль продавца)

| Категория | Персональный токен | Песочница | Коннектор |
|---|---|---|---|
| Вопросы и отзывы | 3 в секунду | 1 в секунду | `Throttle(1, 1 с)` |
| Цены и скидки | 10 за 6 с | 1 в секунду | `Throttle(1, 1 с)` |
| Статистика (заказы) | 1 в минуту, всплеск 10 | нет песочницы | не душит; 429 → «лимит запросов, подождите» |

## Не проверено

- Ни один вызов к WB не делали: нет тестового токена.
- Определение среды по полю `t` — по описанию в документации, на живом токене не проверено.
- Формат ошибок 401/403/429 WB и заголовок с временем ожидания — в коннекторе через общее ядро; на живых ответах
  не сверяли.

## Сценарий

**Селлер WB + модуль `wb-ozon-reviews`.** Утром агент вызывает `wildberries_list_feedbacks` и
`wildberries_list_questions` (ждущие ответа), готовит ответы по `data/facts.md`. Негатив (★1–3) — сразу отдельным
вопросом владельцу; остальное — «Опубликовать N ответов?». По «Да» — `wildberries_propose_*` → подтверждение в
пульте → `wildberries_apply`. Без коннектора — выгрузка отзывов в `data/reviews.csv` и публикация в кабинете руками.

**Модуль `wb-ozon-prices`.** `wildberries_list_prices` дважды в день → сверка с себестоимостью и минимальной ценой
из `data/prices.csv`. Менять цену коннектор не умеет — агент готовит файл для загрузки в кабинет.

**Оценка «минут до/после» (не замерено, оценка):** 30 отзывов в день — открыть каждый в кабинете, написать,
опубликовать ~2 мин → ~60 мин; с коннектором — прочитать пачку черновиков и нажать «Да» ~10 мин. Цены: выгрузка из
кабинета и сверка в таблице ~15 мин → сводка сразу. Замерить на первом клиенте-селлере.

## Подключение в harness

Запись для `portfolio-hq/integrations/servers.json` (добавлена; работает после слияния и появления файла ключа):

```json
"wildberries": {
  "type": "stdio", "command": "python3",
  "args": ["{gas_pult}/src/gas_pult/connectors/wildberries_mcp.py"],
  "env": {"GAS_WILDBERRIES_KEY_FILE": "{secrets}/wildberries.token"},
  "auth": {"kind": "file", "file": "wildberries.token", "keepass": "mcp/wildberries",
           "get_key": "ЛК продавца WB → Интеграции по API → Создать токен → Тестовый (песочница)"}
}
```

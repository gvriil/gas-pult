# Черновик документа

1. Шаблон — в `templates/` по виду документа. Нет подходящего — скажи, какого не хватает; не пиши с нуля.
2. Данные: стороны и реквизиты, позиции, цены, сроки — из `data/` или из сообщения человека. Чего нет — список
   «нужно уточнить» в начале черновика, поле оставь `{не заполнено}`.
3. Заполни **только поля** шаблона. Суммы пересчитай; НДС — по ставке шаблона; сумму прописью сверь с цифрами.
4. Проверь реквизиты навыком `requisites-check`.
5. Договор, претензия, юридическое письмо — первая строка «ЧЕРНОВИК — проверяет юрист».
6. Файл — `outbox/docs/<дата>-<вид>-<контрагент>.md`. Вопрос AskUserQuestion: «<Вид> для <контрагент> на <сумма> ₽
   готов. Что дальше?» — «Отправить», «Изменить», «Оставить черновиком» (для договора и претензии — «Передать
   юристу», «Изменить», «Оставить черновиком»).

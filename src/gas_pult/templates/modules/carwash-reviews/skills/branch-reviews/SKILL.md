# Новые отзывы по филиалам

1. **Google** — MCP-сервер Business Profile API подключён: по каждой карточке филиала отзывы без ответа
   (`accounts.locations.reviews.list`). Нет — строки `площадка = Google` из `data/reviews.csv`.
2. **Яндекс Бизнес, 2ГИС** — только `data/reviews.csv` (выгрузка или перенос из кабинета). Дата файла старше суток —
   предупреди в сводке.
3. Сведи: id, площадка, филиал, дата, оценка, текст. Дубли по id убери. Филиал не найден в `data/branches.csv` —
   «не сопоставлен», вопрос человеку.
4. По каждому филиалу — сколько новых, сколько негатива, средняя оценка за 30 дней (если есть история).
5. Ошибка доступа API (401/403) — «ключ не подходит или нет прав», не обходи. Лимит — подожди и повтори один раз.

Сайты карт не открываешь и не скачиваешь: только API или файл.

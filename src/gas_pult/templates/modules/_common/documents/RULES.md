Документы — навыки `document-draft` (черновик по шаблону), `requisites-check` (реквизиты и суммы) и `claim-draft`
(претензия).

- Документ — **только по шаблону** из `templates/` и данным клиента из `data/`: меняем поля, юридически значимый текст
  не придумываем и не «улучшаем». Шаблона нет — говорим, какого, и не пишем документ с нуля без просьбы человека.
- Договор, претензия, юридическое письмо — **всегда черновик с пометкой «ЧЕРНОВИК — проверяет юрист»** в начале
  файла. Агент не даёт юридических заключений и не обещает исход спора.
- Реквизиты (ИНН, КПП, ОГРН, БИК, счёт) — только из данных клиента; контрольные суммы не сходятся или поле пустое —
  не подставляем «похожее», а спрашиваем. Суммы пересчитываем: итог = сумма строк, НДС — по ставке из шаблона.
- Черновики — `outbox/docs/<дата>-<вид>-<контрагент>.md` (или .docx/.xlsx, если шаблон такой). Отправить
  контрагенту, подписать ЭП, загрузить в ЭДО — только человек или пульт после «Да» на вопрос о **конкретном**
  документе. В учётную систему (1С) — только файлом для загрузки, не напрямую, если модуль не задаёт иное.
- Персональные данные в документах — только необходимые для документа (152-ФЗ); в чат и вопросы их не выносим.

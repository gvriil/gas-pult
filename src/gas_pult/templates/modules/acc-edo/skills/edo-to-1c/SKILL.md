# Файл для 1С из входящих ЭДО

1. Возьми из `registry/<клиент-id>/<ГГГГ-ММ>.csv` строки, которые человек подтвердил («Все» или «По одному» → «Да»),
   и поставь им статус `в реестре`.
2. Допиши их в `outbox/1c/<клиент-id>-<ГГГГ-ММ>.csv` с колонками `файл, вид, номер, дата, контрагент,
   инн_контрагента, сумма, ндс, статус` — как у acc-primary, чтобы бухгалтер грузил одним способом. Строка уже есть
   (тот же вид, номер, дата, контрагент) — не дублируй.
3. Если такой документ уже попал в файл для 1С из первички (сверка `совпало`) — не добавляй второй раз, в отчёте
   напиши «уже в файле acc-primary».
4. Доложи одной строкой: клиент, сколько строк, сумма. Загружает в 1С бухгалтер; подписывает у оператора — человек.

# Сроки предписаний

Скрипт — рядом (рабочие дни — по календарю навыка `workdays`); N и M — из раздела «Настройки» CLAUDE.md
(`report_days`, `warn_days`):

```bash
python3 .claude/skills/order-watch/order_check.py --orders data/orders.csv --evidence evidence \
    --report-days N --warn-days M
```

По каждому открытому пункту: `left` — рабочих дней до срока (0 — сегодня, меньше 0 — просрочено), `report_from` —
с какого дня готовить отчёт (за N рабочих дней до срока), `files` — сколько фото и актов в папке
пункта, `stage` — что делать:

| stage | Что делаешь |
|---|---|
| `в работе` | ничего; в сводку — строкой |
| `напомнить исполнителю` | напоминание исполнителю (`templates/task.md`) — пачкой после «Да» |
| `готовить отчёт` | фото и акты есть — навык `order-report` |
| `не успеваем? нет фото и актов` | вопрос директору: «Пункт <n> предписания <№>: до срока <left> раб. дн., подтверждений нет. Просить продление?» — «Просить продление», «Успеем — напомнить исполнителю», «Позже» |
| `СРОК СЕГОДНЯ`, `ПРОСРОЧЕНО` | сразу вопрос директору с первой строкой «ПРОСРОЧЕНО» или «СРОК СЕГОДНЯ» |

Скрипт отказал «нет производственного календаря» — скажи человеку, сроки не угадывай. Итог дня — `ORDERS.md`
(для сводки директора: открытые пункты, ближайший срок, где нет подтверждений).

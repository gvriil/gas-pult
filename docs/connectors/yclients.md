# Коннектор YCLIENTS (`yclients`)

**Статус: каркас, не проверено на песочнице.** Ответы в `tests/fixtures/yclients/` собраны по документации YCLIENTS API
(зеркало OpenAPI github.com/alexmaltsevgit/yclients-openapi, прочитано через Context7 25.11.2026; первоисточник —
developers.yclients.com). Данные выдуманные. Формат тела и ответа `POST /company/{id}/clients/search` (страницы,
фильтр поиска) в документации описан неполно — проверить первым делом. Доступа к песочнице нет: partner-токен выдаёт
YCLIENTS по письму разработчикам.

Код — `src/gas_pult/connectors/yclients_mcp.py`, тесты — `tests/test_yclients_mcp.py`, контракт — `docs/CONNECTORS.md`.

## Что умеет (только чтение)

| Инструмент | Что делает | Метод API |
|---|---|---|
| `yclients_list_records` | Записи: время, клиент и телефон, мастер, услуги и сумма, статус (ожидается / пришёл / подтвердил / не пришёл), оплачена ли. Фильтры: период, мастер, клиент | `GET /records/{company_id}` |
| `yclients_get_record` | Одна запись | `GET /record/{company_id}/{id}` |
| `yclients_list_clients` | Клиенты: имя, телефон, почта, визитов, потрачено, баланс; поиск по имени или телефону | `POST /company/{company_id}/clients/search` (чтение) |
| `yclients_list_staff` | Сотрудники: должность, работает ли, рейтинг | `GET /company/{company_id}/staff` |
| `yclients_list_services` | Услуги: цена от и до, длительность, активна ли | `GET /company/{company_id}/services` |

Списки — до 100 строк за вызов, постранично (`page`; есть следующая — поле `more`).

## Чего не умеет (и не будет)

- Создавать, переносить, отменять записи; менять клиентов, услуги, расписание.
- Кассу, финансы, абонементы, лояльность, отправку SMS клиентам.
- Запись в сервис в первой версии не реализована вовсе: `propose/apply` нет. Напоминание клиенту уходит через
  модуль пульта и подтверждение человека, а не через API YCLIENTS.

## Как получить ключ (делает владелец)

1. Письмо разработчикам YCLIENTS с запросом partner-токена (marketplace / «для интеграции»); без него API недоступен.
2. user-токен — вход пользователя филиала (метод `POST /auth` по логину и паролю); при смене пароля токен
   перестаёт работать.
3. id филиала — число из адреса в личном кабинете.
4. Файл `~/.config/gastech-mcp/yclients.token` (права 0600):
   `{"partner": "...", "user": "...", "company_id": "4564"}`. Оригинал — KeePassXC `mcp/yclients`.

## Лимиты

Коннектор держит 5 запросов в секунду (консервативно; точный лимит вендора не проверен). 429 — понятная ошибка.

## Сценарий

Модули `fitness-lapsed` и `carwash-return` (`src/gas_pult/templates/modules/`) берут клиентов и последние визиты из
выгрузки. Через коннектор: `yclients_list_clients` + `yclients_list_records(client_id)` дают тот же список «давно не
был» без ручной выгрузки из YCLIENTS. Оценка: сбор списка раз в неделю — было ~30 минут (выгрузка, фильтры в
таблице), станет ~2 минуты (запрос и проверка списка). Оценка расчётная, не измерена.

# Переход по возрасту

1. `python3 .claude/skills/age-transition/age_transition.py --today <сегодня> --children data/children.csv
   --groups data/groups.csv --horizon 60`. В stdout — CSV (группа, возраст, с какой даты, почему, варианты); в
   stderr — пропущенные (нет согласия родителя, нет группы).
2. `TRANSITIONS.md`: по строке — имя ребёнка, группа, с какой даты, варианты; без дат рождения и телефонов.
3. О каждом ребёнке — вопрос «Ребёнок выходит из группы по возрасту — предложить родителю перевод?». «Предложить
   группу» — человек выбирает группу из вариантов; потом черновик `templates/transition.md` родителю и пачка через
   `reminder-batch`.

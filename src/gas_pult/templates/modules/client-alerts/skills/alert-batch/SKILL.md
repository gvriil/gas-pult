# Пачка сообщений

## 1. Что за пачка

- Напоминание о записи (`reminder-visit.md`) — у кого `след_визит` завтра (или сегодня позже текущего часа + 3 ч).
- Напоминание об оплате (`payment-due.md`) — `долг > 0` и `срок_оплаты` сегодня, завтра или уже прошёл.
- Рекламная рассылка (`promo-month.md`) — только по прямой просьбе человека.
Одна пачка — один шаблон.

## 2. Кому можно

Из `data/clients.csv` убери:
- `отписка = да` — всегда;
- без `согласие_уведомления = да` — для напоминаний;
- без `согласие_реклама = да` — для рекламы;
- без контакта для своего канала (`email` пуст при канале email);
- дубли (один человек — одно сообщение в пачке).

Сколько убрано и почему — посчитай (без имён): это видно человеку.

## 3. Черновики

`outbox/<ГГГГ-ММ-ДД>-<шаблон>.md`:

```markdown
# Пачка <дата> · <шаблон> · N сообщений · канал: email
Убрано: 1 — нет согласия, 1 — отписка.

## 1. Иван (id 1, email)
<текст с подставленными полями>
```

Не больше лимита из CLAUDE.md; больше — раздели на пачки и спрашивай по одной. Время отправки попадает в тихие
часы — пачку готовь, а отправку предложи после их окончания.

## 4. Вопрос

AskUserQuestion: «Отправить пачку из N? Шаблон: <имя>. Канал: <…>. Первые: Иван, Мария, Пётр» — варианты «Да» /
«Нет». Канал не подключён — вместо вопроса напиши: «Готово N черновиков в outbox/<файл>, канал не подключён —
отправьте сами или подключите почту в панели».

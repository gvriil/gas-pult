# Прогноз остатков и план поставки

1. **Данные**: API площадок (MCP подключён) или `data/stock.csv`; свой склад — `data/warehouse.csv`. Дата данных — в
   отчёт; файлу больше суток — предупреди.
2. **Скорость** по строке (площадка + склад + артикул): `заказы_28д ÷ max(28 − дней_без_остатка, 7)` шт./день.
   Продаж нет — скорость 0, в план не берём, но в отчёте — «нет продаж 28 дней».
3. **Хватит на**: `(остаток + в_пути) ÷ скорость` дней (скорость 0 — «∞»).
4. **Порог** = срок доставки + запас (из CLAUDE.md). Хватит меньше порога — в план.
5. **Сколько везти** = `скорость × (срок доставки + покрытие) − (остаток + в_пути)`, вверх до кратности короба.
   Сумма по всем складам артикула больше `на_складе` — урежь пропорционально скорости и отметь «не хватает N шт.».
6. **SUPPLY.md**: таблица по площадкам и складам (артикул, хватит дней, везти шт., коробов), отдельно «кончится
   раньше поставки» (хватит < срока доставки — уже не успеваем) и «залежалось» (хватит > 120 дней).
   Копию — в `history/<дата>.md`.
7. **Вопрос** — до шести строк: сколько артикулов в плане, главные три, чего не хватает на своём складе.

# Ответ на отзыв и NPS

1. Возьми новые отзывы (официальный API площадки или выгрузка в `data/`).
2. На каждый — черновик ответа: спасибо, по сути претензии, что делаем. Негатив — без оправданий и споров.
3. NPS за период: промоутеры (9–10) минус критики (0–6), в п.п.; рядом — число ответов.
4. Спроси AskUserQuestion: «Опубликовать N ответов?» — «Да» / «Нет».

Заготовка: подробные правила дополнит отраслевой модуль.

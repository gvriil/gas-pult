## Очередь
План по волнам — `docs/STRATEGY.md`.
1. Теги `v0.1.0`, `v0.2.0` → GitHub Releases (собирает `.github/workflows/release.yml`).
2. Волна 2: Web Push и иконка на экране (PWA), ввод в терминал на «Экране».
3. Сессии в одной папке делили журнал Claude Code; с правилом «одно окно на проект» — реже. Привязать окно к его
   собственному журналу (id сессии).
4. Модель сессии берётся из строки статуса (`🤖 …`) — при другой строке статуса поле пустое; найти надёжный источник.
5. `GEMINI.md`: таблица цветов — ещё старая палитра; в панели уже Material 3 (Gemini) — обновить таблицу.
6. **Переименовать сессию** (просьба владельца 31.10): кнопка «Переименовать» в боте и панели → `tmux rename-window`;
   имя сохраняется в снимке `claude-restore` и переживает перезапуск; проверка — имя не пустое, без `:` и `.`.
7. **Тесты не должны трогать боевой tmux.** 31.10 13:27 проверка lockcheck сделала `TMUX_TMPDIR=<длинный путь> tmux kill-server`:
   сокет не поместился, команда попала в сервер `main` и закрыла 5 окон. В тестах — только `tmux -S <короткий сокет>`
   (например `/tmp/gp-XXXX/s`), без голого `kill-server`; правило — в `CONTRIBUTING.md`.
8. **Подсказка Claude в поле ввода** (просьба владельца 31.10): Claude Code пишет предложенное следующее сообщение бледным
   текстом (`ESC[2m`) после `❯` в строке ввода — читать её из `capture-pane -e`, показывать как placeholder в панели
   и кнопкой в боте; нажатие — вставить текст. Общие заглушки вида `Try "…"` не показывать.
9. **Переписка — главный экран, сессии — вкладки сверху** (выбор владельца 31.10, как у ChatGPT/Claude/Gemini/Grok):
   панель сразу открывает последнюю активную сессию; над чатом — горизонтальная лента вкладок-чипов `[tgi●] [icon◐] …`
   (● работает, ◐ ждёт ответа, без значка — тихо), переключение тапом и свайпом влево-вправо по чату; в конце ленты «+».
   Отдельный экран-список убрать. Сигналы из других сессий — только значок на вкладке, без всплывающих баннеров.
   Долгое нажатие на вкладку — «Переименовать» / «Закрыть» (п. 6).

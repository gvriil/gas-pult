# Коннектор Т-Бизнес (`tbank`)

**Статус: каркас, не проверено на песочнице.** Ответы в `tests/fixtures/tbank/` собраны по документации T-API
(`developer.tbank.ru/docs/api/get-api-v-1-statement`, `.../get-api-v-4-bank-accounts`; прочитано через Context7
26.11.2026). Данные выдуманные. Не проверено: адрес песочницы (в документации есть «тестовый режим», точного адреса
не нашёл — подставляется через `GAS_TBANK_BASE`), формат тела ошибок, набор полей `balances` у валютных счетов.
Доступа к песочнице нет: токен берёт владелец в `developer.tbank.ru`.

Код — `src/gas_pult/connectors/tbank_mcp.py`, тесты — `tests/test_tbank_mcp.py`, контракт — `docs/CONNECTORS.md`.

## Что умеет (только чтение)

| Инструмент | Что делает | Метод API |
|---|---|---|
| `tbank_list_accounts` | Расчётные счета: номер, название, валюта, остаток, доступная сумма. Инвестиционные не показывает | `GET /openapi/api/v4/bank-accounts` |
| `tbank_list_operations` | Выписка за период: приход/расход со знаком, контрагент и ИНН, назначение, статус; итоги периода (остаток на начало и конец, приход, расход); фильтры: счёт, направление, статус, ИНН; постранично (`cursor`) | `GET /openapi/api/v1/statement` |

Дата начала обязательна; даты — ГГГГ-ММ-ДД в UTC, конец периода не включается. Счёт по умолчанию — основной рублёвый.

## Чего не умеет (и не будет)

- Платежи, переводы, платёжные требования, выставление счетов, выпуск сертификатов — **не реализованы вовсе**;
  `propose/apply` нет. Деньги через пульт двигаются только руками человека в банке.
- Менять данные компании, права, карты. Токен для коннектора — **только чтение выписок**.

## Как получить ключ (делает владелец)

1. `developer.tbank.ru` → T-API → подключение; для проверки — тестовый режим (песочница).
2. Токен с правом только на чтение счетов и выписок. Боевой токен выдаём клиенту только после «Да» владельца счёта.
3. Файл `~/.config/gastech-mcp/tbank.token` (права 0600), токен одной строкой. Оригинал — KeePassXC `mcp/tbank`.

## Лимиты

Вендор: 20 запросов в секунду на метод. Коннектор держит 10. Операций за вызов — до 100 (у API до 5000); дальше
по `cursor` из поля `more`. Данные в API — с июня 2023.

## Сценарий

Модули `acc-primary` и `horeca-receivables` (`src/gas_pult/templates/modules/`) сверяют оплаты с долгами по выгрузке
из банка. Через коннектор: `tbank_list_operations(direction=in, from=…)` даёт поступления с ИНН и назначением —
модуль сопоставляет их со взаиморасчётами без ручной выгрузки. Оценка: сверка за неделю — было ~40 минут (выгрузка
выписки, фильтры, сопоставление), станет ~5 минут (запрос и проверка списка). Оценка расчётная, не измерена.

# Рабочие дни РФ

Скрипт — рядом: `python3 .claude/skills/workdays/workdays.py`.

| Команда | Что делает | Пример |
|---|---|---|
| `add <дата> <N>` | срок: N-й рабочий день после даты (дата получения не считается) | `add 2026-11-02 10` → `2026-11-17` |
| `left <срок> [<сегодня>]` | рабочих дней после сегодняшнего до срока включительно: 0 — срок сегодня, <0 — просрочено | `left 2026-11-17 2026-11-02` → `10` |
| `is <дата>` | рабочий ли день | `is 2026-11-04` → `нет` |
| `next <дата>` | ближайший рабочий день с этой даты (для «срок выпал на выходной») | `next 2026-11-07` |
| `years` | на какие годы есть календарь | |

Календарь: `calendar-ru.csv` рядом со скриптом; файл клиента `data/calendar-ru.csv` важнее (тот же формат:
`дата,вид,основание` — вид `выходной` для нерабочих будних дней, `рабочий` для рабочих суббот и воскресений).
Субботы и воскресенья — выходные, если в календаре не сказано иное.

Нет года в календаре — скрипт завершается с кодом 2 и текстом «нет производственного календаря на <год>»: скажи
человеку, не считай сам.

Сверено: 2026 — постановление Правительства РФ от 24.09.2025 № 1466, 2027 — от 17.09.2026 № 1187 (по обзорам
buh.ru и ppt.ru; сверка 02.11.2026). **Обновлять ежегодно; сверять с КонсультантПлюс.**

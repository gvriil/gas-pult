# План сроков

1. Из календаря возьми сроки от сегодня до сегодня + горизонт рабочих дней (`workdays.py add <сегодня> <горизонт>`)
   и всё просроченное за 30 дней. Нет календаря на нужный год — скажи человеку, дальше не считай.
2. Для каждого срока — клиенты, к кому он относится: `все` — всем; `работодатель` — `работодатель = да`;
   `ОСНО` / `УСН-организация` / `УСН-ИП` — по `режим` и `форма`; `НДС` — `ндс = да`.
3. Статус из `data/status.csv` (или 1С, если подключена): нет строки — «не начато».
4. `DEADLINES.md` — по датам: срок (дней осталось — `workdays.py left`), что, клиенты по статусам. Сверху —
   «ПРОСРОЧЕНО», затем «сегодня», «завтра», остальное.
5. Вопросы: просрочено — по одному на клиента; «нет документов» — один вопрос на пачку напоминаний; в тексте до
   шести строк: срок, что, сколько клиентов не готово, первые три названия.

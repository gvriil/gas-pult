# Отправка одобренной пачки

1. Проверь: «Да» получено на вопрос именно об этом файле `outbox/…`, и файл с тех пор не менялся. Иначе — спроси заново.
2. Тихие часы — не отправляй; скажи, когда отправишь, и спроси снова после их окончания.
3. Отправляй по одному сообщению через подключённый канал (почта, Telegram-бот компании, мессенджер клиента).
   Ошибка — не больше одной повторной попытки, дальше — следующее сообщение.
4. Перенеси файл в `outbox/sent/` и допиши итог: отправлено N, ошибок K (по номерам, без контактов), время.
5. Доложи одной строкой: «Отправлено N из M, ошибок K — outbox/sent/<файл>».

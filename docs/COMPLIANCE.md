# Соблюдение условий поставщиков моделей

Пульт сам не продаёт и не перепродаёт доступ к моделям. Он передаёт сообщения в сессии Claude Code и других
моделей, которые работают на сервере владельца, — значит, на сервере действуют условия каждого поставщика.
Здесь — наша политика, официальные страницы поставщиков и чек-лист владельца.

Сверено с официальными страницами **01.11.2026**. Условия поставщиков меняются — сверяйте перед подключением
нового человека, сервера или поставщика. Текст условий для людей пульта — [`docs/TERMS.md`](TERMS.md)
(черновик, на проверку юристу).

## Политика

1. **У каждого человека — свой аккаунт или ключ поставщика.** Одна подписка Claude (Pro, Max) — для одного
   человека: она не делится на нескольких людей и не перепродаётся. Ключи API — свои у каждого, кто работает
   с моделью, или ключ организации по коммерческим условиям поставщика, если они это разрешают.
2. **Страны и поставщики — только по их спискам поддерживаемых регионов.** Человек работает с моделью, только
   если страна, где он находится, есть в списке поставщика (ссылки ниже). Страна не в списке — значит, не
   поддерживается: такой человек с этой моделью не работает. Трафика к моделям из неподдерживаемых стран
   (включая Россию) быть не должно.
3. **Сервер и его выход в интернет — только в поддерживаемой стране.** Сервер пульта и адрес, с которого он
   ходит к API моделей, — в стране из списка поставщика (у нас — Нидерланды). Никаких VPN, прокси и выходов
   через неподдерживаемую страну, никакого обхода ограничений.
4. **Пользовательские соглашения не нарушаем.** Каждый человек пульта при первом входе принимает условия
   использования ([`TERMS.md`](TERMS.md)): он сам отвечает за соблюдение правил поставщиков и законов, а владелец
   вправе в любой момент прекратить доступ. Согласие с версией и датой хранится на сервере.

Что важно из условий (своими словами, точный текст — по ссылкам):

- **Anthropic, Consumer Terms:** нельзя передавать кому-либо логин, ключ API или данные аккаунта и делать свой
  аккаунт доступным другим; нельзя перепродавать сервисы; использование — по политике поддерживаемых регионов.
- **Anthropic, Commercial Terms:** перепродажа — только с одобрения Anthropic; нельзя давать доступ к сервисам
  в страны и лицам под ограничениями; клиент отвечает за всё, что происходит в его аккаунте.
- **Anthropic, Usage Policy:** запрещено давать доступ к продуктам Anthropic в нарушение Supported Regions Policy
  и обходить блокировку через другой аккаунт.
- **OpenRouter:** вы обязаны соблюдать условия каждой модели (Model Terms) и отвечаете за нарушения своих
  пользователей; нельзя продавать или передавать доступ; VPN и прокси для обхода региональных запретов — нельзя.
- **Z.ai и DeepSeek:** ключом нельзя делиться и раскрывать его; запрещено использование в санкционных регионах
  и в их пользу.

## Каналы: MAX, VK и другие российские

Подключение каналов для России (MAX, VK) — **только с поставщиком модели, который разрешён для этого региона.
Claude (Anthropic) для них не используется:** России нет в списке поддерживаемых стран Anthropic, а трафик к модели
из неподдерживаемой страны недопустим, даже если сервер стоит в Нидерландах. То же — для любой модели, у
поставщика которой страны пользователя канала нет в списке. Какие каналы есть и с какими поставщиками — в
[`docs/CHANNELS.md`](CHANNELS.md) (колонка о регионе и разрешённом поставщике).

## Чек-лист владельца

- [ ] **Сервер — в поддерживаемой стране.** Пульт и сессии работают на сервере в стране из списков поставщиков
  (у нас — Нидерланды).
- [ ] **Выход в интернет — там же.** Запросы к API моделей уходят с адреса сервера в этой стране: без VPN-выхода,
  прокси или туннеля через неподдерживаемую страну. Проверка с сервера: `curl -s https://ipinfo.io/country`
  (должна быть страна из списка). VPN на сервере, если он есть, — только для входящих подключений, не для выхода
  к моделям.
- [ ] **У каждого человека — свой вход или ключ.** Участник пульта работает в Claude Code под **своим** аккаунтом
  Claude или со **своим** ключом поставщика. В пульте это поддерживается так: у каждого человека — своя папка
  Claude (свои вход и настройки Claude Code), подписка владельца другим не передаётся.
- [ ] **Подписку не делим и не перепродаём.** Одна подписка Claude — один человек. Доступ к пульту не продаётся
  как доступ к моделям.
- [ ] **Человек — из поддерживаемой страны.** Перед тем как дать роль, уточните, откуда человек будет работать
  и с какими моделями; страна не в списке поставщика — с этим поставщиком он не работает.
- [ ] **Условия приняты.** Каждый человек нажал «Принимаю» (панель → «Настройки» → «Люди»: «условия приняты»
  и дата). Без этого пульт ничего, кроме условий, не показывает.
- [ ] **Нарушение — отключить.** Панель → «Настройки» → «Люди» → человек → «Отключить» (или в боте ⚙️ Настройки →
  👥 Люди → «⛔ Отключить»). Доступ прекращается сразу.
- [ ] **Сверка раз в квартал** — ссылки этой страницы: списки стран и условия меняются.

## Как это устроено в коде

- Версия и короткий текст условий — `src/gas_pult/terms.py` (`VERSION`); полный текст — [`TERMS.md`](TERMS.md).
  Поменяли смысл условий — поднимите `VERSION`: бот и панель спросят согласие у всех заново.
- Согласие: `People.accept(uid, version)` / `People.accepted(uid, version)` (`people.py`). У человека из
  `people.json` — поле `terms: {"version", "at"}` в его записи; владельцев в `people.json` нет, их согласие —
  в `terms.json` рядом (0600).
- Бот: до согласия на любое действие — текст условий и «✅ Принимаю»; вход в панель (`/start login_…`) не
  задерживается. Панель: `GET /api/terms`, `POST /api/terms/accept`; остальное API до согласия отвечает
  `403 {"code": "terms"}`, `/api/meta` — поле `terms: {version, accepted}`.

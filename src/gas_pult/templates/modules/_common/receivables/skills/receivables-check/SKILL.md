# Разбор дебиторки

1. Прочитай выгрузку взаиморасчётов (`data/`): контрагент, документ, сумма, срок оплаты.
2. Посчитай просрочку на сегодня и разбей по корзинам: до 30, 31–60, 61–90, больше 90 дней.
3. Топ-5 должников по сумме — с днями просрочки.
4. Спроси AskUserQuestion: «Что делаем с просрочкой?» — 2–4 варианта (напомнить всем, только >30 дней, позвонить топ-3, ничего).

Заготовка: подробные правила дополнит отраслевой модуль.

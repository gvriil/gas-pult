# Остатки, урожай, заказы

1. Для каждой позиции и каждого дня D на 3 дня вперёд: доступно(D) = остаток с годен_до ≥ D + сбор до D −
   заказы до D (первыми уходят партии с ранним сроком).
2. **Нехватка**: доступно < 0 в день D → заказано, будет, не хватает; кто заказал (рестораны). Замена — позиция
   из `замена` прайса, если её хватает.
3. **Излишек**: свободный остаток (после всех заказов), у которого годен_до ≤ сегодня + surplus_days. Объём в ед. и
   в рублях по себестоимости.
4. **Скидка**: из ряда в настройках — первая, при которой цена × (1 − скидка) ≥ себестоимость; ни одна не проходит —
   предложи «Списать или переработать».
5. **Кому предложить**: рестораны с `согласие_реклама = да`, без отписки, не в стоп-листе; приоритет — кто брал эту
   позицию за 30 дней.
6. `HARVEST.md`: таблица нехватки, таблица излишков (позиция, кол-во, годен до, скидка, цена, кому), «всё в
   порядке: N позиций». Вопросы: сначала нехватка (влияет на завтрашние доставки), затем излишки.

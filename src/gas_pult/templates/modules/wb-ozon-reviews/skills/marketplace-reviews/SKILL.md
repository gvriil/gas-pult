# Новые отзывы с площадок

1. **Wildberries** — MCP-сервер WB API подключён: неотвеченные отзывы и вопросы (API «Вопросы и отзывы»,
   dev.wildberries.ru/openapi/user-communication). Нет — строки `площадка = WB` из `data/reviews.csv` с пустым `ответ`.
2. **Ozon** — MCP-сервер Ozon Seller API подключён: отзывы без ответа (ReviewAPI, docs.ozon.ru/api/seller; нужен
   Premium Plus). Нет — строки `площадка = Ozon` из выгрузки.
3. Сведи в одну таблицу: id, площадка, тип, дата, артикул, оценка, текст. Дубли по id убери.
4. Запиши в сводку, откуда взял (API / выгрузка от <дата файла>) и сколько: «WB: 5 отзывов, 2 вопроса; Ozon: 3».
5. API ответил ошибкой лимита — подожди и повтори один раз; ошибка доступа (401/403) — скажи человеку «ключ
   не подходит или нет прав на отзывы», не пробуй обойти.

Ни в коем случае не открывай сайт или кабинет площадки браузером и не скачивай страницы: только API или файл.

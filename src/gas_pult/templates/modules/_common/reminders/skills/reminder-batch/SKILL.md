# Пачка напоминаний

1. **Кому.** Отбери получателей по задаче модуля (дата записи, срок оплаты, срок заказа) из данных клиента в `data/`.
2. **Убери:** отписавшихся; без согласия на уведомления (для рекламы — без согласия на рекламу); без контакта для
   канала; дубли. Сколько убрано и почему — посчитай без имён.
3. **Черновики** — `outbox/<ГГГГ-ММ-ДД>-<шаблон>.md`:

   ```markdown
   # Пачка 2026-11-03 · <шаблон> · N сообщений · канал: <email/telegram/нет>
   Убрано: 1 — нет согласия, 1 — отписка.

   ## 1. <Имя> (id …)
   <текст шаблона с подставленными полями — только поля, текст шаблона не переписываем>
   ```

   Не больше лимита; больше — несколько файлов. Сейчас тихие часы — готовь, отправку предложи после них.
4. **Вопрос** AskUserQuestion: «Отправить пачку из N? Шаблон: <имя>. Канал: <…>. Первые: <три имени>» — «Да» / «Нет».
   Канал не подключён — вместо вопроса: «Готово N черновиков в outbox/<файл>, канал не подключён — отправьте сами».
5. «Да» — навык `reminder-send`. «Нет» — пачка остаётся черновиком; спроси, что поправить.

# Ценовой страж

1. **Цены**: API площадок (MCP подключён) — текущая цена, скидка, участие в акциях; иначе `data/prices.csv`.
   Экономика (себестоимость, комиссия, логистика, мин_цена) — всегда из `data/prices.csv`.
   Нет себестоимости — артикул в отчёт «нет себестоимости», сигнал не считаем.
2. **Цена вчера** — из API-истории, `цена_вчера` в выгрузке или `history/prices-<вчера>.csv`. Сохрани цены дня в
   `history/prices-<сегодня>.csv`.
3. **Сигналы** (по строке площадка + артикул):
   - `красный` — цена продажи < мин_цена или маржа < 0;
   - `жёлтый` — маржа ниже порога; изменение к вчера больше порога скачка; акция с маржой ниже порога.
4. **Предложение**: минимальная цена, при которой маржа ≥ порога и цена продажи ≥ мин_цена; шаг не больше
   max_step % от текущей. Пересчитай маржу при предложенной цене — покажи «было → станет».
5. **PRICES.md**: таблица сигналов (артикул, площадка, цена, маржа, причина, предложение) и «всё в порядке: N».
6. **Вопросы** — по одному на сигнал, сначала красные; больше пяти сигналов — сначала общий вопрос «N сигналов,
   главные три: … Разбирать по одному?» («Да», «Только красные», «Позже»).

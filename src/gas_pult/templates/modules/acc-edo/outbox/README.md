# Черновики и файлы для 1С

- `outbox/1c/<клиент-id>-<ГГГГ-ММ>.csv` — файл для загрузки в 1С (колонки как у модуля acc-primary). Загружает
  бухгалтер.
- `outbox/docs/` — черновики запросов контрагенту об исправлении. Отправляете вы сами — через оператора ЭДО или
  почтой. Отправленное — в `sent/`.

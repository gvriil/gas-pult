# Политика обработки персональных данных — устройство и черновик

Аудит 24.11 (35 проверок): `/privacy` отвечал 404, в анкетах `/q/` не было согласия, версия условий расходилась
(код — 02.11, страница — 17.11). Владелец: «да, передай gas-pult политику, согласие и версию условий».

## Что есть

- **`/privacy`** — без входа, русский и английский (`/privacy?lang=en` → `/privacy#en`). Шаблон —
  `src/gas_pult/web/privacy.html`, версия и дата — `privacy.VERSION`. Пока `privacy.PUBLISHED = False`, наверху —
  плашка «Черновик — не опубликовано». Опубликовать — `PUBLISHED = True` пулл-реквестом после «да» владельца.
- **`/terms`** — версия и дата из `terms.VERSION`: сервер подставляет `{{VERSION}}`, `{{DATE_RU}}`, `{{DATE_EN}}`.
  Поднять `terms.VERSION` — все люди примут условия заново (`People.accept`, как раньше).
- **Согласие** — отдельная галочка «Согласен(на) на обработку персональных данных по Политике», ссылки на `/privacy`
  и `/terms` открываются в новой вкладке:
  - анкета `/q/` — на шаге «Проверьте и отправьте». Черновик — без галочки. Отправка без `privacy: true` — 409
    `code=privacy`;
  - фокус-ссылка — перед первым открытием (`POST /api/focus/open`). Почему здесь: открытие — единственная дверь,
    через которую проходит каждое новое устройство; до него сервер не получил от человека ни сообщений, ни голоса,
    ни файлов. Отказ не тратит место устройства. Согласие — на ссылку (`focus:<id>`): второе устройство той же ссылки
    не спрашивается. Не спрашиваем: демо и протокол встречи (только просмотр), ссылка на пространство «для себя».
- **Журнал** — `consents.json` (0600, только добавление, `consents.record_doc`): кто (`form:<id ссылки>`,
  `focus:<id ссылки>`), документ (`privacy`, `terms`), версия, `sha256` — SHA-256 отданных байтов страницы той версии
  (с данными оператора), время. Поменялся текст той же версии — новая запись с новым хешем.

## Оператор — файл вне git

Репозиторий публичный: данных оператора в коде, тестах и коммитах нет. Страница читает их на каждый запрос из
`<каталог настроек>/operator.toml` — по умолчанию `~/.config/gas-pult/operator.toml` (`GAS_PULT_CONFIG_DIR`).
Нет файла или поля — на странице «[ЗАПОЛНИТЬ]». Поля можно писать в корне или в разделе `[operator]`:

```toml
[operator]
name = "…"      # ФИО ИП или название компании
inn = "…"       # ИНН
ogrnip = "…"    # ОГРНИП
address = "…"   # адрес для писем
email = "…"     # почта для запросов о данных
phone = "…"     # телефон
```

Права файла — 0600 (`chmod 600`). После правки перезапуск не нужен. Внимание: правка оператора меняет текст страницы
и её хеш — новые согласия запишутся с новым хешем, старые остаются как были.

## Сверить у юриста

Места помечены комментарием `сверить у юриста` в `privacy.html`:

1. Статус оператора (ИП в РФ или компания в ЕС), представитель в ЕС (GDPR ст. 27), уведомление Роскомнадзора
   (152-ФЗ ст. 22).
2. Правовое основание для каждой цели (152-ФЗ ст. 6, 9; GDPR ст. 6) и форма согласия.
3. Трансграничная передача (152-ФЗ ст. 12; GDPR гл. V). Страны проверены только для Z.ai (Сингапур) и DeepSeek (КНР)
   — отчёт портфеля о поставщиках 17.11; страны Anthropic, OpenRouter, ElevenLabs — дописать после проверки.
4. Сроки ответа на запросы людей (152-ФЗ ст. 14, 20; GDPR ст. 12).
5. Сроки хранения, которых нет в коде (на странице — «[ЗАПОЛНИТЬ]»): записи людей, ответы анкет, файлы `inbox`,
   голосовые из Telegram-бота, журнал согласий.

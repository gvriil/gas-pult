# Черновики

Агент кладёт сюда черновики: `reports/<дата>-отчёт-<предписание>.md` — уведомление об исполнении предписания,
`extension/<дата>-ходатайство-<предписание>.md` — ходатайство о продлении срока, `tasks/<дата>-<исполнитель>.md` —
поручения исполнителям. Подписывает и отправляет в жилищную инспекцию человек; отправленное — в `sent/`.

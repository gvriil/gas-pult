# Реестр входящих ЭДО

`registry/<id клиента>/<ГГГГ-ММ>.csv`: оператор, документооборот, файл, вид, номер, дата, контрагент,
инн_контрагента, сумма, ндс, сверка, подпись, статус.

- `оператор` — Диадок, СБИС, Контур или «выгрузка»; `документооборот` — номер у оператора (как в кабинете).
- `сверка` — `совпало`, `расхождение: …`, `нет в первичке`, `дубль` (навык edo-match).
- `подпись` — `не нужна`, `ждёт решения`, `подписывает человек`, `отказ (решение человека)`, `подписан` (по данным
  оператора). Агент не подписывает никогда.
- `статус` — `черновик` → `в реестре` после «Да» бухгалтера.

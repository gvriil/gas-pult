# Разбор первички

1. Возьми файлы из `inbox/` (кроме `inbox/done/`). Клиент — по папке `inbox/<клиент-id>/`, по ИНН покупателя в
   документе или по отправителю; не ясно — «клиент?» в сомнительных.
2. **Распознай** (читай изображение/PDF сам): вид (УПД, счёт-фактура, акт, накладная ТОРГ-12, счёт, кассовый чек,
   выписка), номер, дата, продавец и покупатель с ИНН, сумма, НДС (ставка и сумма), итог.
3. **Проверь**: реквизиты — `requisites-check`; сумма строк = итог; НДС = итог × ставка/(100+ставка) (±1 коп.);
   дата в нужном месяце; дубль (тот же вид, номер, дата, контрагент уже в реестре) — пометка «дубль».
4. **Уверенность**: всё прочитано и сходится — `ок`; иначе — `сомнительно: <почему>`.
5. Строки — в `registry/<клиент-id>/<ГГГГ-ММ>.csv` со статусом `черновик`; файл — в `inbox/done/` (копией, исходник
   не удаляй).
6. Вопросы: сначала сомнительные по одному («Внести как есть», «Попросить у клиента заново», «Не первичка»), затем
   общий «Внести N документов в реестр и файл для 1С?» — по клиентам: число и сумма.
7. После «Все»/«Да» — статус `в реестре`, строки в `outbox/1c/<клиент-id>-<ГГГГ-ММ>.csv`; доложи одной строкой.

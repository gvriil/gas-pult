# Черновики

Агент кладёт сюда: `reminders/` — пачки напоминаний собственникам, `docs/` — претензии и заявления о выдаче
судебного приказа (первая строка — «ЧЕРНОВИК — подписывает юрист»), `peni/` — расчёты пеней. Подписывает и подаёт
документы юрист УК; отправленное и поданное — в `sent/` с датой.

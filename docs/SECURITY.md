или ловушку в данных, а не на агента, который сознательно пользуется своей оболочкой. Подробно — разделы «Излишние
полномочия агентов» и «Что закрывает только отдельный пользователь Linux».

## Излишние полномочия агентов

Что агент Claude Code в окне пульта может сам, без «Да» в панели:

- **Bash от пользователя владельца** — тот же пользователь Linux, что у службы панели и бота. Режим разрешений
  решает Claude Code (`permissions` и режим в `settings.json` папки Claude), не пульт. Значит, агент может:
  прочитать файлы 0600 владельца (ключи коннекторов, `secrets.json`, хранилище сессий панели); записать черновик
  с любым `summary`; записать себе сессию панели и нажать «Да» через API; поменять код пульта и перезапустить
  службу (docs/BRIDGE.md, «Граница «Да»»). Хуки `secrets_guard` и `injection_guard` ловят ошибки модели и ловушки,
  а не намеренный обход.
- **Инструменты MCP**: всё, что человек подключил в Claude Code (`mcp.py`, область `user`), плюс мессенджеры
  (`msg-<svc>`, `messengers/panel.py`) и коннекторы пульта. Коннекторы пульта пишут только черновиком; коннекторы
  claude.ai (почта, Диск, GitHub и др.) пульт не ограничивает — у них свои права (например, отправка письма или
  удаление файла без нашего «Да»). Выключить интеграцию на один чат — `chatmcp.py` (`--disallowedTools`).
- **Мост к компьютеру**: чтение страниц — сразу; «Отправить / Оплатить / Удалить», код на странице, запись на Маке,
  команды терминала — черновик и «Да» на сервере (`bridge.py:571`). Переход на адрес — сразу (пробел ASI02).
- **API v1** (1С, CRM): только белый список путей, «Да», команды, люди и ключи — никогда (`access.py:226`).

Пространства клиентов — другое: агент там — отдельный пользователь Linux в песочнице systemd, данные панели ему
не видны и не доступны на запись (docs/TENANTS.md).

## Что закрывает только отдельный пользователь Linux для службы панели

Нужен sudo владельца. Служба панели (`gas-pult-webapp`) и бот работают от отдельного пользователя (например,
`gaspult-web`); код пульта и данные службы (хранилище сессий, `approvals` и журналы) — не на запись пользователю
владельца, под которым работают агенты. Это закрывает:

1. **Обход «Да»**: агент не запишет себе сессию панели и не нажмёт «Да» через API (ASI03, LLM06).
2. **Правку кода и журналов пульта**: агент не поменяет проверки и не сотрёт след (ASI10).
3. **Подложный черновик**: папку черновиков и файлы ключей коннекторов можно отдать службе, агенту — только
   `propose` через MCP (ASI09, LLM02).
4. **Чтение ключей коннекторов и `secrets.json`** агентом (LLM02).

Что не закрывает: Bash агента в своей папке и коннекторы claude.ai — это решает режим разрешений Claude Code и
песочница окна (как у пространств).

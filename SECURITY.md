# Безопасность

gas-pult даёт управлять машиной из Telegram. Ниже — что защищает, от чего не защищает и как сообщить об уязвимости.

## Модель угроз

| Что | Как устроено |
|---|---|
| Кто может управлять | Только Telegram ID из `owners` в `config.toml`. Сообщения и нажатия остальных молча отбрасываются. |
| Токен бота | `~/.config/gas-pult/token` с правами 0600 (или `GAS_PULT_TOKEN`). В логах и сообщениях об ошибках маскируется. |
| ▶️ Выполнить | Команда идёт `bash -lc` от вашего пользователя, в папке окна, без stdin, таймаут 10 минут. Опасное (`rm -r`, `--force`, `reset --hard`, `DROP`, `reboot`, `kill` …) — второе подтверждение. |
| sudo | Только по `sudo_allow`, принудительно с `sudo -n` (без запроса пароля). Работает, если вы сами настроили sudo без пароля для этих команд. |
| Вывод команд | Похожее на токены (JWT, токены Telegram и GitHub, `sk-…`, `password=…`) маскируется. Маскирование эвристическое и не гарантирует полноту. |
| Данные | Распознавание и синтез речи — локально. Наружу ходит только Telegram Bot API (`api.telegram.org`). |
| Входящие файлы | Сохраняются в `~/.local/share/gas-pult/inbox` (0700), путь передаётся Claude. |

## Чего gas-pult не делает

- **Не защищает от утечки токена.** У кого токен, тот может читать, что бот шлёт вам. Управлять он не сможет —
  ID проверяется на каждом сообщении, — но токен всё равно отзывайте сразу: @BotFather → `/revoke` → `gas-pult init`.
- **Не защищает аккаунт Telegram.** Кто вошёл в ваш Telegram, тот управляет машиной. Включите облачный пароль
  (двухэтапную проверку) и следите за активными сеансами.
- **Не изолирует Claude.** Пульт передаёт ваши сообщения как обычный ввод. Режим разрешений Claude Code
  (`/permissions`) остаётся вашей главной защитой. Не включайте режим «всё разрешено» на машинах с ценными данными.
- **Не шифрует историю.** `state.json` и `cmds.json` (последние 200 команд) лежат в открытом виде с правами 0600.

## Рекомендации

- Отдельный бот на каждую машину, не публикуйте его имя.
- `sudo_allow = []`, если sudo по кнопке не нужен.
- Добавьте в `foreign` шаблоны команд, которые никогда не должны выполняться кнопкой (`'\bssh\s+prod\b'`).
- Обновляйтесь: `./install.sh` ещё раз или `uv tool upgrade gas-pult`.

## Сообщить об уязвимости

Не открывайте публичный issue. Используйте приватное сообщение на GitHub:
**Security → Report a vulnerability** (https://github.com/gvriil/gas-pult/security/advisories/new).
Ответим в течение 7 дней. Исправления выпускаются для последней версии.

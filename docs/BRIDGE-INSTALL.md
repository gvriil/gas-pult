# Подключение моста в несколько нажатий — исследование (владелец 17.11)

Задача: мост к браузеру и «руки на компьютере» должен подключить человек без компьютерных навыков (пожилые, люди с
ограниченными возможностями — миссия портфеля). Сейчас нужно: поставить Node 22, скачать файл, две команды в
Терминале, вручную включить «Запись экрана» и перезапустить Терминал. Это слишком сложно.

## Что проверено

| Факт | Источник |
|---|---|
| Неподписанное приложение, скачанное браузером, macOS не откроет двойным щелчком: «Системные настройки → Конфиденциальность и безопасность → Открыть → Открыть всё равно» (кнопка живёт около часа), затем пароль | Apple, https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac |
| В macOS Sequoia обход «правый щелчок → Открыть» убран, остался только путь через «Конфиденциальность и безопасность» | 9to5mac 13.08.2024, https://9to5mac.com/2024/08/13/security-bite-apple-finally-making-it-harder-to-override-gatekeeper-is-a-telling-move/ (не Apple) |
| Файлы, скачанные `curl`, не получают метку карантина `com.apple.quarantine` — Gatekeeper их не проверяет (так ставятся Homebrew и Claude Code) | Unit 42, https://unit42.paloaltonetworks.com/gatekeeper-bypass-macos/ |
| Node «один исполняемый файл» (SEA) — экспериментальный (Stability 1.1); macOS x64 в CI Node не проверяется; на macOS нужна подпись (`codesign --sign -`) | https://nodejs.org/api/single-executable-applications.html |
| Windows SmartScreen предупреждает о скачанном файле без репутации; репутация — у известных файлов и подписей | https://learn.microsoft.com/en-us/windows/security/operating-system-security/virus-and-threat-protection/microsoft-defender-smartscreen/ |
| Подпись для Windows — Azure Artifact Signing (бывш. Trusted Signing), Basic $9.99/мес | https://azure.microsoft.com/pricing/details/artifact-signing/ |
| Мост на Node 22 работает на macOS 11 (Big Sur), снимок экрана — после «Запись экрана» для Терминала | живая проверка 17.11 на Маке владельца |

Не проверено: цена Apple Developer Program (по памяти — $99 в год, на странице Apple цифры не нашёл); снимает ли
`Invoke-RestMethod` на Windows метку «из интернета» (Mark of the Web); как macOS выдаёт «Запись экрана» мосту,
запущенному через launchd (гипотеза: разрешение просит сам `node`, а не Терминал); открывается ли нужный раздел
настроек ссылкой `x-apple.systempreferences:com.apple.preference.security?Privacy_ScreenCapture` на Big Sur.

## Чего не обойти ни в одном варианте

1. Расширение «Playwright Extension» в Chrome — одно нажатие «Установить» в Chrome Web Store (мост откроет страницу).
2. Первый раз — выбор вкладки в окне расширения (одно нажатие).
3. «Запись экрана» — только если нужен снимок экрана; macOS требует, чтобы это включил сам человек.

## Варианты

| | Как выглядит для человека | Нужно от нас | Плюсы | Минусы |
|---|---|---|---|---|
| **А. Одна команда** | Панель → «Подключить компьютер» → большая кнопка «Скопировать» → открыть Терминал (картинка, где он) → вставить → Enter. Дальше всё само | Скрипт `install.sh` / `install.ps1` на панели: скачивает Node (официальный архив, сверка SHA256), мост, делает пару по коду из команды, ставит автозапуск (`~/Library/LaunchAgents`, на Windows — «Автозагрузка»), открывает страницы расширения и «Записи экрана» | Без денег, сегодня; `curl` — без Gatekeeper; без пароля администратора; автозапуск | Один шаг в Терминале: пожилому — с помощником или по телефону |
| **Б. Подписанное приложение** | Ссылка или QR → скачать → двойной щелчок → всё само | Apple Developer ID и нотаризация (macOS), подпись Windows (Azure, $9.99/мес); сборка .pkg/.app и .exe с Node внутри | Настоящий «двойной щелчок», без предупреждений | Деньги и время сборки; SEA Node — экспериментальный; нужно «да» владельца |
| **В. Неподписанный файл** (.command / .app) | Скачать → двойной щелчок → «нельзя открыть» → Настройки → «Открыть всё равно» → пароль | Только файл | Без денег | Хуже А: путь через настройки сложнее команды, а на Sequoia — ещё сложнее; приучает обходить защиту (Apple: «самый частый путь заражения») |

## Рекомендация

1. **Сейчас — вариант А** (без денег, честно и надёжно): одна команда из панели, установка без прав администратора,
   автозапуск при входе, пара по коду внутри команды, понятные экраны с картинками («где Терминал», «Запись экрана»).
   Проверка — на Маке владельца (Big Sur) и на Windows 10/11.
2. **Затем — вариант Б**, если владелец скажет «да» деньгам: подписанный установщик для macOS и Windows. Тогда для
   человека останется «скачать → дважды щёлкнуть».
3. Вариант В не делаем: он учит обходить защиту системы.

Готово, когда: вариант А установлен с нуля на Маке владельца одной командой, мост сам поднимается после перезагрузки,
снимок экрана работает; время и число нажатий записаны.

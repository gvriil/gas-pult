# Аудит демо «Гаврилы» глазами нового человека (25.11.2026)

> Задача владельца 24.11: «критичнее подойти к демоверсии, она не должна быть корявой… светлую тему чуть контрастнее,
> чтобы был „породистый“… все команды, где нужно подтвердить или выбрать, стилизовать как в ChatGPT или Claude…
> при „Открыть проект“ — понятный красивый список чатов; проработать все области и меню».
> Только отчёт; правки — отдельными PR по 1–3 экрана.

Как проверено: демо `/?demo` на `main` (после #494), Chromium, ширина 390 (светлая) и 1366 (светлая); снимки —
`~/drive/gas-pult/2026-11-25-аудит-демо/` (20 файлов). Ошибок в консоли нет ни на одном экране. Сравнение с ChatGPT и
Claude — по их общедоступному интерфейсу, без снимков чужих продуктов. Gemini не привлекался.

Не снято (кнопки не нашлись по селекторам — проверить руками): меню чата «⋯», «Новый чат» на 390, лист задач.

## Пять главных проблем

1. **Демо открывается в чужом чате, а не на главной** (390, 4-й день по обзору UI). Человек из QR видит переписку
   «Тесты комнат» и терминал — не понимает, что это и куда смотреть. У ChatGPT/Claude первый экран — пустой чат с
   приветствием и подсказками.
2. **Вопросы и разрешения не стилизованы как карточки выбора.** В простом режиме вопрос агента — узкая жёлтая полоса
   «Ждут вашего Да» с обрезанным текстом и кнопкой «Открыть»; варианты видны только после нажатия. У Claude и
   ChatGPT вопрос — карточка в ленте: заголовок, текст целиком, варианты крупными кнопками, описание под каждым.
3. **«Доверять этой папке?» мелькает оранжевой карточкой** при новом чате и проекте. Пульт отвечает «Да» сам
   (`botparts/monitor.py` `trust_auto`), но проверка экрана идёт раз в 3 с, а панель опрашивает экран чаще — вопрос
   успевает показаться.
4. **Служебные строки на виду у нового человека:** «Лимит: 21% до ср 01:05 · Лимит на неделю: 91%» прямо в поле
   ввода; «Инструкций нет (CLAUDE.md) · Файлы: 0 · ~/projects/icon» в шапке проекта; блок «Терминал 7 строк · Last
   login…» в переписке; модели строчными «opus / sonnet / haiku».
5. **Светлая тема блёклая:** серый текст второго плана, тонкие светлые рамки, много белого на белом; акцент — один
   синий; карточки без глубины. Не хватает «породы»: плотности, контраста, ритма отступов.

## Отдельно (из задачи штаба)

**(а) «Доверять этой папке».** Причина — гонка: панель показывает вопрос раньше, чем `trust_auto` (опрос раз в 3 с)
нажмёт «Да». Правка в 2 шага: 1) панель не рисует карточку `trust` для окна, открытого пультом, а показывает
«Открываю папку…» (S); 2) `trust_auto` сразу после создания окна, не дожидаясь цикла монитора (S). Заранее «доверить»
папку в настройках Claude Code — только после проверки, есть ли для этого документированная настройка (не проверено).

**(б) Диалоги выбора и подтверждения** — один компонент «карточка выбора» для вопроса агента, разрешения,
незнакомого диалога и выбора модели: заголовок (что), текст (зачем, целиком), варианты крупными кнопками с описанием,
«Свой ответ» / «Отмена». Цвета — акцент и нейтральный, без оранжевого фона (оранжевый — только значок «ждёт»).

**(в) Светлая тема.** Предложение (проверить расчётом контраста до правки): текст второго плана темнее (с `#4B5563`
к `#374151`), рамки карточек на тон темнее, фон страницы — тёплый светло-серый, карточки — белые с тенью `--shadow-sm`;
акцент — один насыщенный цвет, второй — для «ждёт ответа»; отступы по сетке 4/8/12/16/24; заголовки — плотнее (600).
Цель — AA для всего текста (≥ 4,5:1), для подписей — не ниже 4,5:1, не «приглушённым» серым.

**(г) «Открыть проект» → список чатов** — см. строку 10: название чата, последнее сообщение (одна строка), время,
статус точкой; «Новый чат» вверху; «Завершённые» — свёрнуто.

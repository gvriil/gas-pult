# Публикация ответов

1. Проверь, что «Опубликовать» получено на эти ответы и файл `outbox/reviews-<дата>.md` с тех пор не менялся.
2. Интеграция площадки подключена (официальный API, ключ клиента) — публикуй по одному ответу; ошибка — одна
   повторная попытка, дальше следующий. Лимиты API площадки соблюдай: между запросами — пауза, как в документации.
3. Интеграции нет — сделай `outbox/reviews-<дата>-to-publish.md` (id отзыва → текст) и скажи человеку, что
   публиковать нужно в кабинете площадки вручную. Сам в кабинет не заходи и браузером не публикуй.
4. Перенеси файл в `outbox/sent/`, допиши итог: опубликовано N, ошибок K (по id), время.

# API v1 — подключить 1С, CRM, телефонию

Решение владельца 22.11 (правило «API с первого дня»): внешние системы подключаются к тому же ядру, что и панель, без
переписывания. `/api/v1/<путь>` — псевдоним `/api/<путь>` панели; вход — токеном, а не cookie или Telegram.

Код: `src/gas_pult/apitokens.py` (токены и журнал), `src/gas_pult/access.py` (таблица `V1_*`),
`src/gas_pult/webapp.py` (`H.v1_call`). Тесты — `tests/test_api_v1.py`.

## Как выпустить токен

1. Откройте панель → «Настройки» → «ИИ, подключения и бюджет» → «Токены для 1С и CRM».
2. Введите имя (например, «1С Бухгалтерия»). Имя нужно, чтобы потом знать, что отзывать.
3. Нужна запись (создавать задачи, писать агенту)? Поставьте галочку «Запись». Без неё — только чтение.
4. Выберите срок: 30 дней, 90 дней, год (по умолчанию) или 2 года.
5. Нажмите «Выпустить токен» и сразу скопируйте его. Токен показывается один раз — на сервере хранится только
   его отпечаток (sha256).

Кто выпускает:

- владелец пульта — токены с данными владельца;
- человек пространства (участник или админ пространства) — токены только со своим пространством.

Каждый видит и отзывает только свои токены. Наблюдателю, участнику без пространства, фокус-ссылке и ссылке на
пространство токены не выдаются.

## Пример запроса

```bash
# список сессий (чатов)
curl -H "Authorization: Bearer $TOKEN" https://<адрес панели>/api/v1/sessions

# переписка сессии @1
curl -H "Authorization: Bearer $TOKEN" "https://<адрес панели>/api/v1/history?w=@1"

# новая задача (нужен токен с «Запись»)
curl -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"title": "Перезвонить клиенту", "next": "позвонить до обеда"}' \
  https://<адрес панели>/api/v1/tasks/add

# сообщение агенту в сессию @1 (нужен токен с «Запись»)
curl -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"w": "@1", "text": "Новый заказ из CRM"}' https://<адрес панели>/api/v1/send
```

В 1С — `HTTPСоединение` и `HTTPЗапрос` с заголовком `Authorization` = `Bearer <токен>`; ответ — JSON.
Ответы — те же, что у панели для того же пути.

## Права (таблица `access.V1_GET` / `access.V1_POST`)

Белый список. Путь не из списка — 403, даже если такой путь есть у панели.

| Группа   | Чтение (GET)                                                                                   | Запись (POST, галочка «Запись») |
|----------|------------------------------------------------------------------------------------------------|---------------------------------|
| sessions | `sessions`, `projects`, `project`, `project/sessions`, `project/history`, `history`, `last`, `activity` | —                    |
| tasks    | `tasks`                                                                                        | `tasks/add`, `tasks/update` (без `kind=command` и `cmd`) |
| drafts   | `drafts` — «Ждут вашего Да», только смотреть                                                   | —                               |
| send     | —                                                                                              | `send` — сообщение агенту       |

Дальше действуют обычные права того, кто выпустил токен: токен человека пространства видит только своё
пространство (как `Handler.space()`), задачи владельца ему закрыты.

**Никогда через токен** (`access.V1_NEVER`), даже с «Запись»: «Да» и «Нет» на черновики (`drafts/yes`,
`bridge/confirm`), выполнение команд и терминал, задачи с командой сервера, удаление и запуск задач, люди и роли,
ключи, сами токены, платежи, мессенджеры, настройки (`prefs`, модель по умолчанию, уведомления, лимиты).

## Ответы с ошибкой

| Код | Когда |
|-----|-------|
| 401 | нет токена, токен неизвестен, отозван, срок вышел; у выпустившего больше нет прав или он в другом пространстве |
| 403 | путь не из белого списка; запись токеном «только чтение»; задача с командой; права выпустившего не позволяют |
| 429 | больше 20 неверных токенов с одного адреса за минуту |

## Журнал

Каждый вызов `/api/v1` — строка в `api-tokens-log.jsonl` в папке данных пульта (0600, запись под `flock`):

```json
{"t": 1795000000.0, "id": "a1b2c3d4e5f6", "m": "GET", "p": "/api/v1/sessions", "c": 200}
```

Только время, id токена (пусто для неизвестного), метод, путь без параметров и код ответа. Тела запросов и
параметры (в них бывают имена и телефоны) не пишутся. Файл больше 5 МБ переносится в `.1`.
В списке токенов панели — «последнее использование» (не чаще раза в минуту).

## Хранение

`api_tokens.json` (0600, `store.locked`): id, sha256 токена, имя, кто выпустил, пространство, запись, группы,
создан, до, отозван, последнее использование. Отозванные остаются в списке с пометкой — для разбора журнала.

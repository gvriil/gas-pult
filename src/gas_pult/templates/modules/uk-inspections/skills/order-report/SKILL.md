# Отчёт об исполнении и ходатайство о продлении

**ЧЕРНОВИК — подписывает директор, проверяет юрист.** Агент не направляет документы в инспекцию и не заходит в её
системы и в ГИС ЖКХ.

## Отчёт об исполнении

1. Пункты предписания с одним сроком — одним отчётом (`templates/report.md`). По каждому пункту: что сделано, дата,
   приложения — файлы из `evidence/<предписание>/<пункт>/` (имя файла → «Приложение N»). Нет подтверждения у пункта —
   пункт в «не исполненные к сроку», не выдумывай «выполнено».
2. Файл — `outbox/reports/<дата>-отчёт-<предписание>.md`, первая строка — пометка о черновике; список приложений —
   с путями, чтобы человек собрал пакет.
3. Вопрос AskUserQuestion: «Отчёт по предписанию <№> (N пунктов, срок <дата>) готов — что дальше?» —
   «Подпишу и отправлю», «Изменить», «Не готово — ждём фото».
4. Человек сказал, что отправил, — статус пунктов `выполнен` в `data/orders.csv` (после ответа), копия — в
   `outbox/sent/`. Ответ инспекции (принято, внеплановая проверка) — вносит человек.

## Ходатайство о продлении

Только после ответа директора «Просить продление». Шаблон — `templates/extension.md`: причины (не зависящие от УК —
погода, поставка, допуск в квартиру, подрядчик; с подтверждением), что уже сделано, план с датами и новый срок.
Файл — `outbox/extension/<дата>-ходатайство-<предписание>.md`. Подать нужно **до истечения срока** исполнения —
в вопросе укажи, сколько рабочих дней осталось. Решение о продлении принимает орган надзора; до решения срок прежний.

# Стоп-отгрузка

1. Кандидат: долг > лимита **или** просрочка больше допустимой (из правил модуля; по умолчанию — 14 дней).
2. Вопрос AskUserQuestion: «Стоп-отгрузка для <контрагент>? Долг <сумма> ₽, лимит <лимит> ₽, просрочка <дни> дн.,
   последняя оплата <дата>» — «Да», «Нет», «Напомнить и подождать 3 дня».
3. «Да» — строка в `outbox/stop-list.csv` (`контрагент,с,причина,кто_решил`) и черновик вежливого уведомления клиенту
   (уходит отдельной пачкой после «Да»). В учётную систему или складу — только тем каналом, что задан в модуле;
   нет канала — человек вносит сам.
4. Снятие: оплата видна в свежей выгрузке и долг ≤ лимита — вопрос «Снять стоп-отгрузку для <контрагент>?» — «Да» / «Нет».
   Слова должника «оплатили» — не основание: ждём выгрузку или подтверждение человека.
5. Список действующих стопов — в каждой утренней сводке модуля.

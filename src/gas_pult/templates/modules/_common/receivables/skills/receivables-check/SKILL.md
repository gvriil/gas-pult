# Разбор дебиторки

1. Прочитай выгрузку взаиморасчётов в `data/` (контрагент, документ, дата, сумма, оплачено, срок оплаты) и лимиты
   (`limit`, отсрочка) — если есть. Дата выгрузки — в сводку; старше суток — предупреди.
2. Остаток по документу = сумма − оплачено; просрочка = сегодня − срок оплаты (календарные дни).
3. Корзины: не наступил срок, 1–30, 31–60, 61–90, >90 — сумма и число контрагентов.
4. Топ-5 по просроченной сумме; отметь тех, кто **сверх лимита** (долг > лимит) или с просрочкой больше
   допустимой — кандидаты на стоп-отгрузку.
5. Для каждого просроченного — следующий шаг лестницы (навык `debt-steps`).
6. Полностью — `RECEIVABLES.md`; в вопрос — до шести строк: всего, просрочено, >30 дней, сверх лимита, топ-3.
   AskUserQuestion «Что делаем с просрочкой?» — 2–4 варианта по ситуации (например: «Напомнить всем по лестнице»,
   «Только >30 дней», «Стоп-отгрузка: <имя>», «Ничего сегодня»).

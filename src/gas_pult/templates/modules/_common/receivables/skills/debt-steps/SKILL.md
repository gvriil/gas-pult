# Лестница по долгу

| Когда | Шаг | Как |
|---|---|---|
| за 3 дня до срока | мягкое напоминание | пачка через блок напоминаний (`reminder-batch`) |
| день просрочки | напоминание о просрочке | пачка, шаблон «оплата просрочена» |
| 7-й день | второе напоминание | пачка; в тексте — сумма и документ, без угроз |
| 14-й день | звонок | задача человеку в сводке: кому, сумма, история |
| 30-й день | претензия | черновик через блок «Документы» (`claim-draft`), проверяет юрист |
| сверх лимита | стоп-отгрузка | навык `stop-shipment` |

- Шаг уже делали (история в `outbox/sent/`) — не повторяй, предложи следующий.
- Должник ответил «оплачу до …» — запиши обещание в `outbox/promises.csv`; до этой даты лестницу не двигай,
  после — напомни человеку «обещал <дата>, оплаты нет».
- Рассрочку и списание не предлагаешь должнику сам — только человеку вариантом кнопки.
